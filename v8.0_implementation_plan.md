# v8.0 Smart Phone Cataloguer Implementation Plan

## Phase 1: Photo Capture Integration
- Reuse photo_capture.py PhotoCaptureEngine
- Add batch photo selection workflow
- Support phone gallery import (simulated via file dialog)
- Store captured photos in temp directory for processing

## Phase 2: OCR Identification Integration
- Reuse ocr_identification.py OCRIdentificationEngine
- Process each photo through OCR
- Extract: denomination, year, country, mint mark
- Display results with confidence scores
- Allow manual correction of OCR errors

## Phase 3: Collection Matching
- Reuse collection_intelligence.py CollectionIntelligenceEngine
- Match OCR results against existing collection items
- Detect duplicates (exact match, fuzzy match)
- Identify series gaps (missing dates/varieties)
- Display match results with recommendations

## Phase 4: Cataloguing Workflow
- Reuse coin_collection.py CoinCollection and CoinItem
- Auto-populate fields from OCR + matching
- Minimal manual entry: grade, notes, purchase info
- Review screen before adding to collection
- One-click "Add to Collection"
- Batch processing support

## Phase 5: GUI Integration
- Add Tools -> Smart Phone Cataloguer menu item
- Create dialog with mobile-friendly layout
- Photo preview panel
- OCR results panel
- Match results panel
- Cataloguing form panel
- Progress indicators for batch processing
- Export batch results to CSV/JSON

## Testing Strategy
- Unit tests for SmartPhoneCataloguer orchestration
- Integration tests with mocked Photo Capture, OCR, and Collection Intelligence
- Fixture-based tests with sample images
- Regression tests: must pass with existing 911+ tests

- Photo Capture Engine (v7.4)
- OCR Identification Engine (v7.4)
- Collection Intelligence Engine (v7.4)
- Coin Collection models (v7.4)
