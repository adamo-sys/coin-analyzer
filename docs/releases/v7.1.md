# v7.1 Platform Analytics

## Scope

v7.1 adds deterministic platform analytics for monitoring and insights across all major Collector Platform subsystems. The analytics engine measures module health, activity, completeness, and performance using local data only - no AI, forecasting, machine learning, cloud analytics, or external APIs.

## Implemented Features

### Platform Analytics Engine (`platform_analytics.py`)

**Core Components:**
- `PlatformAnalyticsEngine`: Main analytics engine for generating snapshots, summaries, health scores, and dashboards
- `AnalyticsMetric`: Single metric with name, value, type, description, and timestamp
- `AnalyticsTrend`: Trend over time for a metric with direction and change percentage
- `ModuleMetrics`: Metrics for a specific platform module with health score and activity level
- `AnalyticsSnapshot`: Point-in-time snapshot of platform analytics across all modules
- `AnalyticsSummary`: Summary of analytics with strengths, improvements, and module counts
- `PlatformHealthScore`: Comprehensive health score with component scores, explanations, and recommendations
- `AnalyticsDashboard`: Complete dashboard with snapshot, summary, health score, and trends

**Module Metrics Generated:**
- Collection Intelligence: total items, unique countries, unique denominations, graded items
- Portfolio Performance: total estimated value, acquisition cost, unrealized gain/loss, silver exposure
- Workflow Integration: photos captured, OCR sessions, identification success rate, entry completion rate, workflow completion rate
- Deal Hunter: listings processed, buy/pass recommendation rates, risk flags
- Opportunity Engine: opportunities generated, high-priority rate
- Market Intelligence: market records, comparable sales
- Watchlists & Alerts: watchlists, watchlist items, alerts generated
- Collector Cloud: snapshots created, sync plans generated
- Sync & Backup: backup archives, last backup age, sync simulations, backup readiness
- Multi-Device Workspace: registered devices, workspace snapshots
- Device Linking: linked devices, unresolved conflicts

**Health Score Components:**
- Module Coverage: Percentage of active modules
- Backup Readiness: Backup status and recency
- Workflow Completeness: Workflow completion rates
- Metadata Quality: Collection grade and year coverage
- Collection Completeness: Collection activity level

**Export Support:**
- Markdown export for snapshots and health scores
- CSV export for snapshots and health scores

### GUI Integration (`coin_collection_gui.py`)

**Platform Analytics Dialog:**
- Added "Platform Analytics" to Tools menu

- Generate Analytics button to create snapshot from current state

## Guardrails

v7.1 adheres to the following guardrails:
- **No AI:** Analytics are deterministic calculations, not AI recommendations
- **No Forecasting:** No predictions or future projections
- **No Machine Learning:** No ML models or training
- **No Cloud Analytics:** All analytics use local data only
- **No External APIs:** No external service calls or data sources
- **Deterministic:** All metrics are calculated from local platform state
- **Read-Only:** Analytics engine does not modify any data
- **Export-Only:** Export functionality writes to user-selected files only
