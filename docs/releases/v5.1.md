# Coin Analyzer v5.1

## Overview

v5.1 adds Phone Photo Capture, a metadata-only field photo intake workflow for organizing phone-captured coin, banknote, and listing photos.

This release does not perform image recognition, attribution, grading, OCR identification, cloud sync, automatic collection entry, purchasing, or collection mutation.

## Major Features

- `photo_capture_workflow.py` with `PhotoCaptureWorkflow`, `CapturedPhoto`, `PhotoCaptureSession`, and `PhotoCaptureReport`.
- Single photo capture records with timestamp, source type, photo role, workflow status, review status, notes, and links to candidate or collection metadata.
- Coin front/back and banknote front/back capture sessions with missing-side checks.
- Optional listing-photo sessions for dealer, auction, or listing intake.
- OCR-ready and review-ready status summaries.
- Photo Vault record conversion for captured photo metadata.
- OCR source adapters for future OCR-assisted workflows.
- Mobile Collector Companion summary integration.
- Tools -> Phone Photo Capture GUI workflow.
- CSV and Markdown export.

## Architecture Highlights

- Establishes a photo intake layer that future OCR-assisted identification and mobile entry releases can consume.
- Reuses Photo Vault metadata concepts and OCR Experiment/OCR Validation adapter patterns.
- Keeps capture state separate from ownership records so field photos cannot mutate the collection.
- Keeps Mobile Collector Companion aware of photo capture readiness without creating a second recommendation or identification engine.
