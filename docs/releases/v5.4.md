# Coin Analyzer v5.4

## Overview

v5.4 adds Collector Workflow Integration, a complete review-only workflow session layer for the v5 mobile collector arc.

This release coordinates photo capture, OCR identification, evidence review, collection context, collection entry candidates, portfolio impact previews, and final review. It does not add cloud sync, internet services, automatic purchases, automatic collection mutation, or AI grading. Collector review remains mandatory.

## Major Features

- `collector_workflow_integration.py` with `CollectorWorkflowIntegrationEngine`, `WorkflowStage`, `WorkflowSession`, `WorkflowCompletionReport`, and `WorkflowHealthReport`.
- End-to-end workflow: Photo Capture -> OCR Identification -> Evidence Review -> Collection Context -> Collection Entry Candidate -> Portfolio Impact Preview -> Final Review.
- Review checkpoints with APPROVE, REJECT, and REVIEW decisions.
- Workflow session model with session id, timestamps, photos, OCR candidates, evidence, collection context, entry candidates, portfolio previews, review decisions, warnings, and resume/reopen support.
- Workflow health reporting for completed workflows, abandoned workflows, review escalations, confidence distribution, and stage completion rates.
- Portfolio preview integration through Mobile Collection Entry and Portfolio Performance context.
- Mobile Collector Companion workflow summary integration.
- Tools -> Collector Workflow Integration GUI workflow.
- CSV and Markdown export for workflow completion reports and workflow health reports.

## Architecture Highlights

- Reuses Phone Photo Capture for photo session metadata.
- Reuses OCR-Assisted Identification for OCR candidate generation and evidence.
- Reuses Mobile Collection Entry for proposed collection-entry candidates and preview-only approved-entry records.
- Reuses Portfolio Performance through existing mobile entry preview data.
- Reuses Mobile Collector Companion as the field-facing summary surface.
- Keeps all workflow output review-only and side-effect-free.
