# v6.3 Device Linking & Conflict Resolution

Status: locally implemented; full-suite audit passed.

## Scope

v6.3 creates an offline device-linking and conflict-resolution layer for modeling how multiple devices interact with the same collector workspace.

Architecture:

- `device_linking.py`
- `DeviceLinkingEngine`
- `LinkedDevice`
- `DeviceRelationship`
- `DeviceLinkReport`
- `WorkspaceLinkMap`
- `ConflictResolutionEngine`
- `ConflictCase`
- `ConflictAnalysis`
- `ConflictRecommendation`
- `ConflictResolutionReport`
- `DeviceLinkReadinessReport`

The release builds on v6.0 Collector Cloud Foundation, v6.1 Sync & Backup, and v6.2 Multi-Device Collector Workspace. It adds review-driven device linking, relationship mapping, conflict analysis, recommendations, and readiness reporting without real synchronization or automatic resolution.

## Implemented Features

- Linked device records with relationship role, link status, capability coverage, module coverage, last activity, and sync readiness.
- Device relationship mapping for Primary Device, Secondary Device, Mobile Device, Tablet Device, and Backup Device.
- Capability overlap reporting between linked devices.
- Conflict detection for collection, workflow, portfolio, watchlist, settings, and snapshot conflicts.
- Conflict classification as LOW, MEDIUM, or HIGH.
- Review-only recommendations: MERGE, KEEP_PRIMARY, KEEP_SECONDARY, REVIEW_REQUIRED, and REJECT.
- Workspace link maps with linked devices, relationships, capability overlap, conflict exposure, and sync readiness.
- Readiness reports for linked devices, unresolved conflicts, merge exposure, backup coverage, workspace health, and recommendations.
- Multi-Device Workspace integration through workspace snapshots and health reports.
- Collector Cloud and Sync & Backup integration through the existing workspace engine.
- Tools -> Device Linking & Conflict Resolution.
- Markdown and CSV export for `DeviceLinkReport`, `WorkspaceLinkMap`, `ConflictResolutionReport`, and `DeviceLinkReadinessReport`.
