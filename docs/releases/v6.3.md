# v6.3 Device Linking & Conflict Resolution

Status: in development.

## Scope

v6.3 creates an offline device-linking and conflict-resolution layer for modeling how multiple devices interact with the same collector workspace.

Planned architecture:

- `device_linking.py`
- `DeviceLinkingEngine`
- `LinkedDevice`
- `DeviceRelationship`
- `DeviceLinkReport`
- `WorkspaceLinkMap`
- `ConflictResolutionEngine`
- `ConflictCase`
- `ConflictAnalysis`
- `ConflictRecommendation`
- `ConflictResolutionReport`
- `DeviceLinkReadinessReport`

The release builds on v6.0 Collector Cloud Foundation, v6.1 Sync & Backup, and v6.2 Multi-Device Collector Workspace. It is intended to add review-driven device linking, relationship mapping, conflict analysis, recommendations, and readiness reporting without real synchronization or automatic resolution.

## Guardrails

v6.3 is offline architecture only. It does not add internet sync, real cloud providers, user accounts, authentication services, automatic conflict resolution, background sync, or collection mutation. Collector review remains mandatory.
