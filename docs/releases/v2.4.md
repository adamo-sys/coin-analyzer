# Coin Analyzer v2.4

Release date: 2026-06-18

Release hash: See verified tag `v2.4`

## Overview

Coin Analyzer v2.4 adds the Mobile Companion Prototype. This is a local desktop prototype proving that the Collector Operating System can support mobile-style dealer-table usage without building a native mobile app, web app, API server, OCR workflow, image recognition, scraping, live pricing, cloud sync, or a new database.

The release answers the practical workflow question: can a collector enter minimal candidate details and get a concise BUY/PASS-style recommendation quickly?

## Major Features

- `MobileCompanionWorkflow` for a single candidate -> analysis -> recommendation path.
- `MobileCandidateEntry` for minimal dealer-table input: title, price, shipping, notes, URL, photo reference ID, and source.
- `MobileAnalysisReport` with recommendation, impact score, quality delta, series delta, WANT_LIST status, top reason, concise summary, warnings, and max rational price.
- Provider abstraction points:
  - `StorageProvider`
  - `PhotoProvider`
  - `ExportProvider`
- `PhoneWorkflowSimulation` and `PhoneWorkflowReport` for deterministic coin-shop workflow checks.
- Dashboard mobile summary support for last mobile recommendation, last analyzed candidate, and top mobile opportunity.
- Persistence support for recent mobile candidates and recent mobile recommendations using the existing local JSON app-state system.
- CSV and Markdown export for Mobile Analysis Reports and Phone Workflow Reports.

## Architecture Notes

- Mobile Companion reuses Listing Analyzer, Acquisition Workflow, Acquisition Impact, Smart Shopping Assistant, Photo Vault metadata, Collection Dashboard, and Persistence Manager.
- It does not duplicate owned/duplicate/upgrade/recommendation logic.
- Provider abstractions are desktop defaults only and exist to reduce future mobile coupling.

## Known Limitations

- No native mobile app, iPhone app, Android app, web app, API server, OCR, image recognition, scraping, live pricing, cloud sync, or new database.
- Mobile Companion uses existing deterministic parsing and recommendation engines; ambiguous candidates still require review.
- Photo references are metadata lookups only and do not inspect image contents.
- Provider abstractions are local desktop implementations, not mobile providers.
