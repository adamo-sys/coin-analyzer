# Coin Analyzer v5.3

## Overview

v5.3 adds Mobile Collection Entry, a review-only field workflow that turns OCR-assisted identification output into proposed collection-entry records.

This release does not insert records automatically, make ownership decisions, grade coins automatically, sync to cloud services, purchase, bid, or mutate collection data. Approval prepares a preview record for manual save only.

## Major Features

- `mobile_collection_entry.py` with `MobileCollectionEntryEngine`, `CollectionEntryCandidate`, `CollectionEntryReview`, and `CollectionEntryReport`.
- Photo/OCR text -> OCR Candidate -> Collection Entry Candidate -> Review -> Approved Entry Record preview pipeline.
- Candidate fields for country, year, denomination, series, monarch, variety, grade estimate, certification number, notes, and acquisition source.
- Per-field confidence and overall HIGH/MEDIUM/LOW confidence classification.
- Collection context review for already owned, duplicate, possible upgrade, collection gap, WANT_LIST/watchlist match, and review-required scenarios.
- Manual review decisions: APPROVE, REJECT, REVIEW, with reasoning, evidence, confidence, relevance, and approved-entry preview data.
- Portfolio impact previews for collection size, priority impact, collection gap impact, and collection value impact.
- Field workflows for Coin Show, Dealer Visit, Coin Shop, Auction Preview, and Antique Market.
- Tools -> Mobile Collection Entry GUI workflow.
- Mobile Collector Companion summary integration.
- CSV and Markdown export.

## Architecture Highlights

- Reuses OCR-Assisted Identification instead of creating a second identification parser.
- Reuses Focused Collection Intelligence for owned/duplicate/upgrade/gap/WANT_LIST context.
- Reuses Watchlists & Alerts for watchlist context.
- Reuses Portfolio Performance for preview-only portfolio context.
- Keeps collection entry as a proposed record until the collector manually acts outside this workflow.

## Known Limitations

- Mobile Collection Entry is advisory and preview-only.
- Manual review is mandatory.
- No automatic collection insertion, ownership decision, AI grading, cloud sync, purchase, bid, or mobile-native app.
- OCR quality depends on source image quality and OCR text quality.
- GUI smoke could not run in this environment because Python/Tk cannot find a usable `init.tcl`.
