# Coin Analyzer v2.6.1

## Overview

v2.6.1 adds an OCR Validation Layer so collectors can judge whether OCR output is trustworthy before using it in any manual workflow.

This is a trust and safety release. Validation output remains advisory and never modifies collection records, ownership records, grades, recommendations, shopping rankings, or acquisition decisions.

## Major Features

- `OCRValidationEngine` for deterministic validation of OCR suggestion reports.
- `OCRValidationReport` for trust level, validation score, findings, warnings, explanations, and review recommendations.
- `OCRTrustLevel` values: HIGH, MEDIUM, and LOW.
- `OCRValidationScore` with strengths, weaknesses, and recommended actions.
- `OCRValidationExplanation` explaining why a trust level was assigned.
- Tools -> OCR Experiment now displays validation output below the raw OCR suggestion report.
- Markdown and CSV export for OCR validation reports.

## Validation Checks

- Year format, plausible ranges, conflicting candidates, and ambiguous digit readings.
- Denomination format, conflicting denomination candidates, and possible 5/50 confusion.
- Country recognition quality, conflicting countries, and incomplete country names.
- Certification-number format consistency, malformed values, and incomplete values.
- Overall OCR quality, incomplete OCR text, low confidence OCR, and source OCR warnings.

## Warning System

Validation reports can surface warnings such as:

- Ambiguous Year
- Ambiguous Denomination
- Ambiguous Country
- Incomplete OCR
- Low Confidence OCR
- Conflicting OCR Results
- Manual Review Required

## Known Limitations

- Validation does not make OCR authoritative.
- Trust levels are deterministic rules, not AI confidence.
- Validation identifies ambiguity and conflicts but does not resolve attribution.
- Manual collector review is still required before using any OCR-derived field.
