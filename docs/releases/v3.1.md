# Coin Analyzer v3.1

## Overview

v3.1 adds the eBay.ca Coin Deal Hunter MVP.

Deal Hunter evaluates manually supplied or CSV-imported eBay.ca-style listing rows against Adam's collection priorities, current collection context, WANT_LIST targets, acquisition rules, local market observations, and existing collection-intelligence engines.

This release does not scrape websites, use browser automation, require eBay API credentials, fetch live listing pages, or claim live market-pricing accuracy.

## Major Features

- `DealListing` input model for title, CAD price, CAD shipping, seller/source, listing URL, optional end time, optional image URL, and description.
- CSV import for eBay.ca-style listing rows.
- Sample fake listing CSV fixture stored under `test_data/deal_hunter/`.
- Deterministic title/description parser for country, year, denomination, grade, slab companies, and priority keywords.
- Slab detection for ICCS, CCCS, PCGS, NGC, BCS, and PMG.
- Banknote and chartered banknote keyword detection.
- Collection-aware status classification through existing engines.
- Deterministic scoring:
  - priority score
  - liquidity score
  - collection-fit score
  - risk score
  - max rational price
- Recommendations:
  - BUY
  - WATCH
  - PASS
  - NEGOTIATE
  - REVIEW
- Counterargument generation before BUY.
- Workflows -> Deal Hunter GUI.
- App-state persistence for recent Deal Hunter listings and reports.
- CSV and Markdown export.

## CSV Format

Supported columns:

- `title`
- `price_cad`
- `shipping_cad`
- `seller`
- `source`
- `listing_url`
- `end_time`
- `image_url`
- `description`

All pricing is treated as CAD. If currency is not CAD or cannot be verified as CAD, Deal Hunter flags the listing for REVIEW or PASS depending on collection relevance and risk.

## Scoring Philosophy

Deal Hunter scoring is deterministic local guidance only.

It considers:

- collection status
- WANT_LIST status
- upgrade potential
- gap-filling value
- Adam-specific priorities
- seller/source context
- shipping cost
- missing or vague details
- certification/slab metadata
- local market-awareness records when available

Max rational price is internal rule-based guidance. It is not live market pricing, appraisal, or a guarantee of value.

## Adam Buying Rules

Deal Hunter applies these deterministic rules:

- Canadian sellers preferred.
- CAD pricing only.
- Shipping included in total cost.
- Upgrades over duplicates.
- Pass if cool but not collection-relevant.
- Explicit counterargument generated before BUY.

Priority boosts include:

- Newfoundland
- Canadian silver
- 1859 Large Cent varieties
- 1973 Large Bust quarter
- 1926 Near 6 nickel
- Canadian banknotes
- Chartered banknotes

Risk factors include:

- high shipping
- missing grade
- vague title
- uncertain country or denomination
- raw coin with ambitious grade language
- non-Canadian irrelevant item
- unclear currency
