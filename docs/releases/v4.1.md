# Coin Analyzer v4.1

## Overview

v4.1 adds Live Source Validation, a trust and reliability layer for live listing data.

v4.0 introduced controlled, user-triggered live opportunity discovery. v4.1 makes that safer by validating listings before they enter Deal Hunter, Opportunity Engine, Ranking, or Market Intelligence.

## Major Features

- `live_source_validation.py` with `LiveSourceValidator`, `ValidationResult`, `ValidationWarning`, `ValidationSummary`, `SourceHealthReport`, `LiveSourceValidationReport`, and `ListingFreshness`.
- Required-field validation for title, price, URL, seller, and source.
- Currency validation for CAD, USD, and unknown currency without conversion or exchange-rate lookup.
- Freshness validation with `FRESH`, `STALE`, and `UNKNOWN`.
- URL validation for empty, malformed, duplicate, and unsupported-scheme URLs.
- Source health scoring with `HEALTHY`, `WATCH`, and `UNHEALTHY`.
- REVIEW escalation for high shipping, missing seller, vague title, missing description, stale listing, unknown currency, and suspicious metadata.
- Live Deal Hunter pipeline gating before CandidatePool, Ranking, and Market Intelligence.
- Tools -> Live Source Validation GUI workflow.
- CSV and Markdown exports for validation reports.

## Validation Architecture

Live Source Validation runs before live listings reach recommendation workflows:

Live source
-> validation
-> valid listings only
-> CandidatePool
-> Deal Hunter Ranking
-> Market Intelligence

Invalid listings are rejected from the recommendation pipeline. Uncertain listings can remain valid but require review.

## Known Limitations

- Validation is deterministic and conservative.
- The system does not repair malformed listings.
- The system does not convert currencies.
- The system does not fetch exchange rates.
- The system does not guarantee that a source is truthful.
- The system does not scrape pages, automate browsers, bid, buy, poll in the background, or mutate collection data.
