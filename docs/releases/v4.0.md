# Coin Analyzer v4.0

## Overview

v4.0 introduces Live Deal Hunter as a controlled beta. It is the first user-triggered live opportunity discovery workflow in Coin Analyzer.

The release keeps the project safety model intact: live data can be fetched only when the collector explicitly presses the analyze button. The app does not bid, buy, mutate collection records, scrape web pages, automate a browser, log in to services, run background jobs, or claim live market-pricing accuracy.

## Major Features

- `live_deal_hunter.py` with `LiveDealHunter`, `LiveListing`, `LiveListingBatch`, `LiveDealHunterReport`, `LiveListingSource`, and `RSSListingConnector`.
- Public RSS/XML feed parsing with default eBay.ca RSS-style source support.
- Listing validation flags for stale listings, unknown currency, non-CAD currency, missing price, missing title, duplicate URL, invalid URL, missing URL, missing timestamp, and unknown seller.
- Listing normalization into existing Deal Hunter and Ranking data models.
- CandidatePool integration for accepted live listings.
- Deal Hunter Ranking integration for opportunity prioritization.
- Market Intelligence integration for top ranked live listings.
- Tools -> Live Deal Hunter GUI workflow with RSS URL input, timeout input, report display, CSV export, and Markdown export.

## Safety Guardrails

- No purchases.
- No bids.
- No collection mutation.
- No background polling.
- No scheduled fetching.
- No scraping.
- No browser automation.
- No account login.
- No eBay API integration.
- No live pricing guarantee.

## Known Limitations

- Controlled beta RSS/XML source support only.
- Public feed availability can change outside the application.
- Automated tests use deterministic local RSS fixtures rather than live network calls.
- Currency conversion is not implemented; non-CAD listings are flagged.
- Validation is conservative and report-only.
- v4.0 does not implement advanced source trust scoring; that belongs in v4.1 Live Source Validation.
