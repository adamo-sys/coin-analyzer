# v8.3 Phase 3 Design — Reports Panel

## Status

DESIGN ONLY — awaiting approval before implementation.

## Scope

**Phase 3 adds a unified Reports Panel to `CollectorWorkspace`.** It provides a menu/aggregator of all existing report engines without generating reports eagerly. Each report is generated lazily on demand. Export is delegated to existing engine methods.

### In Scope
- `get_reports()` — returns a `ReportsMenu` of available report descriptors (no eager generation)
- `generate_report(name)` — lazily generates a specific report by querying the engine
- `export_report(name, format, path)` — delegates to engine's export method
- `ReportDescriptor` dataclass — metadata for each report type
- `ReportsMenu` dataclass — menu structure with categories
- Unit + integration tests

### Out of Scope (confirmed)
- GUI — Phase 5
- Persistence — no new JSON file, no new storage
- New analytics — zero business logic
- Eager report generation — reports are generated lazily on demand
- Custom export logic — delegates to existing engine export methods

```python
# New dataclasses
@dataclass
class ReportDescriptor:
    """Metadata for a single report type available in the workspace."""
    name: str                           # e.g., "collection_quality"
    title: str                          # e.g., "Collection Quality Report"
    category: str                       # e.g., "Collection Health"
    description: str                    # e.g., "Scores collection quality across categories"
    engine_name: str                    # Key for _create_engine lookup
    method_name: str                   # e.g., "generate_report"
    has_markdown_export: bool = False
    has_csv_export: bool = False
    available: bool = True             # False if engine context is missing

@dataclass
class ReportsMenu(WorkspaceReport):
    """Menu of all available report types."""
    reports: List[ReportDescriptor] = field(default_factory=list)
    categories: List[str] = field(default_factory=list)
    total_reports: int = 0
    available_reports: int = 0

    def by_category(self, category: str) -> List[ReportDescriptor]:
        return [r for r in self.reports if r.category == category]

    def by_name(self, name: str) -> Optional[ReportDescriptor]:
        for r in self.reports:
            if r.name == name:
                return r
        return None

# New methods on CollectorWorkspace

def get_reports(self) -> ReportsMenu:
    """Return a menu of all available report types. No eager generation."""

def generate_report(self, name: str) -> Dict[str, Any]:
    """Lazily generate a specific report by name. Returns the report as a dict."""

def export_report(self, name: str, format: str, path: str) -> bool:
    """Export a specific report to a file. Delegates to engine's export method."""
```

## Implementation Details

### `get_reports()` — Lazy Menu

```python
def get_reports(self) -> ReportsMenu:
    """Return a menu of all available report types. No eager generation."""
    if "reports" in self._cache:
        return self._cache["reports"]

    menu = ReportsMenu()
    errors: List[str] = []

    # Build report descriptors from registry
    registry = self._report_registry()
    menu.reports = [desc for desc in registry]
    menu.categories = sorted(set(r.category for r in menu.reports))
    menu.total_reports = len(menu.reports)
    menu.available_reports = sum(1 for r in menu.reports if r.available)

    menu.engine_errors = errors
    self._cache["reports"] = menu
    return menu

def _report_registry(self) -> List[ReportDescriptor]:
```

### `generate_report(name)` — Lazy Generation

```python
def generate_report(self, name: str) -> Dict[str, Any]:
    """Lazily generate a specific report by name. Returns the report as a dict."""
    menu = self.get_reports()
    descriptor = menu.by_name(name)
    if not descriptor:
        raise ValueError(f"Unknown report: {name}")
    if not descriptor.available:
        raise RuntimeError(f"Report '{name}' is not available (missing engine context)")

    # Special handling for reports that require the operating system
    if descriptor.engine_name == "collector_operating_system":
        engine = self._get_engine(descriptor.engine_name)["health"]
        report = getattr(engine, descriptor.method_name)()
    else:
        engine = self._get_engine(descriptor.engine_name)
        report = getattr(engine, descriptor.method_name)()

    return report.to_dict() if hasattr(report, "to_dict") else dict(report)
```

### `export_report(name, format, path)` — Delegated Export

```python
def export_report(self, name: str, format: str, path: str) -> bool:
    """Export a specific report to a file. Delegates to engine's export method."""
    menu = self.get_reports()
    descriptor = menu.by_name(name)
    if not descriptor:
        raise ValueError(f"Unknown report: {name}")

    if format == "markdown":
        if not descriptor.has_markdown_export:
            raise ValueError(f"Report '{name}' does not support markdown export")
        method = "export_markdown"
    elif format == "csv":
        if not descriptor.has_csv_export:
            raise ValueError(f"Report '{name}' does not support CSV export")
        method = "export_csv"
    else:
        raise ValueError(f"Unsupported format: {format}")

    # Generate the report first
    engine = self._get_engine(descriptor.engine_name)
    if descriptor.engine_name == "collector_operating_system":
        engine = engine["health"]
    report = getattr(engine, descriptor.method_name)()

    # Delegate to engine's export method
    export_method = getattr(engine, method, None)
    if export_method is None:
        # Some engines have export on the report object, not the engine
        export_method = getattr(report, method, None)
    if export_method is None:
        raise ValueError(f"No export method found for report '{name}'")

    return export_method(path)
```

## Error Handling Strategy

Same as Phase 1/2: **panel warning, not crash.**

- `get_reports()`: Never fails. If an engine is missing, the descriptor is still listed with `available=False`.
- `generate_report()`: If engine fails, raises exception (caller handles it).
- `export_report()`: If engine fails, raises exception (caller handles it).

## Special Cases

1. **Collector Operating System** — The health report engine lives inside the OS dict. Special handling in `generate_report()` and `export_report()` to use `engine["health"]`.

2. **Collection Snapshot** — Requires `create_snapshot()` + `latest_report()`. Special handling to generate a snapshot first, then get the latest report.

3. **AI Grading** — `assess_batch()` requires candidates. In Phase 3, if no candidates are available, the report is marked `available=False`.

4. **Watchlist Scan** — Requires watchlists. If `self._watchlists` is None, the report is marked `available=False`.

5. **Photo Vault** — Requires `photo_records`. If `self._photo_records` is None, the report is marked `available=False`.

## Guardrails

- **No eager generation:** `get_reports()` only returns metadata. No engine is called.
- **No new analytics:** `generate_report()` only calls existing engine methods.
- **No duplicate export logic:** `export_report()` delegates to existing engine methods.
- **No persistence:** No new JSON file, no database.
- **No GUI:** Phase 3 is engine-only.
- **No new algorithms:** No ML, no CV.
- **Read-only:** Workspace queries and presents. Mutation flows through existing tools.
- **Lazy initialization:** Engines created on first access.
- **Error resilience:** Missing context marks reports as unavailable, not crashed.
