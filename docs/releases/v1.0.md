# Coin Analyzer v1.0

Release hash: `2c3d68bc65fcb2f3787f9a3d7624bd49675684c7`

Release date: 2026-06-16

## Overview

Coin Analyzer v1.0 is the first stable release baseline for Adam's local collector decision-support application. It combines collection management, read-only legacy portfolio staging, collection gap analysis, WANT_LIST context, upgrade detection, duplicate detection, and deterministic acquisition guidance.

The release is designed to answer the practical collector question: "Should I buy this?" using local collection data and rule-based analysis only.

## Major Features

- Collection Intelligence Engine for reusable owned, duplicate, upgrade, gap, want-list, not-relevant, and needs-review classification.
- Collector Decision Center style workflow through Tools -> Do I Own This? for manual candidate analysis.
- Upgrade Detection for better-grade replacements, same-grade duplicates, lower-grade candidates, raw/certified considerations, and priority series.
- Duplicate Detection routed through shared collection intelligence in Buy Advisor and Upgrade Advisor.
- WANT_LIST Integration from staged legacy workbook acquisition intent, including explicit target matching and context-aware candidate analysis.
- Acquisition Workflow with deterministic max rational price guidance and BUY/PASS/WATCH/NEGOTIATE/REVIEW recommendations.
- Collection Gap Report with missing dates, completion percentages, priority acquisition suggestions, and CSV export.
- Want List Generator with CSV and Markdown export.
- Legacy Portfolio Import Preview for safe staging of workbook data without writing to `data/collection.json`.
- Melt Value Engine and Portfolio Dashboard as supporting collection-health tools.

## Architecture Highlights

- `focused_collection_intelligence.py` is the decision source for manual candidate classification.
- `acquisition_workflow.py` builds purchase guidance on top of focused collection intelligence without duplicating owned, duplicate, or upgrade logic.
- `buy_advisor.py` and `upgrade_advisor.py` route duplicate and upgrade decisions through collection intelligence while preserving user-visible behavior.
- `legacy_portfolio_importer.py` stages legacy workbook inventory and WANT_LIST rows without mutating production collection data.
- Tests rely on isolated fixtures in `test_data/` and the project runner `run_tests.bat`.

## Known Limitations

- Acquisition pricing is deterministic internal guidance, not live market pricing.
- No web scraping, OCR expansion, image recognition expansion, Numista API integration, or live pricing API is included in v1.0.
- WANT_LIST context loaded in Do I Own This? is session-local.
- GUI testing is mostly smoke-based rather than full automated UI interaction coverage.
- JSON storage remains simple and may need replacement if the collection grows substantially.
- Experimental image/OCR modules remain manual-verification-only and are not part of the decision source.
