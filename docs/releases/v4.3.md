# Coin Analyzer v4.3

## Overview

v4.3 adds Watchlists & Alerts so the collector can define active targets and scan existing candidate outputs for matching opportunities.

This release is report-driven and user-triggered. It does not add notifications, background polling, scheduled jobs, automatic purchasing, bidding, live pricing, or collection mutation.

## Major Features

- `WatchlistEngine` for matching collector-defined watches against candidate outputs.
- `Watchlist`, `WatchlistItem`, and `WatchlistMatch` models.
- Watch types for series watches, specific coin watches, keyword watches, and custom watches.
- `WatchPriority` levels: `CRITICAL`, `HIGH`, `NORMAL`, and `LOW`.
- Adam starter presets for Newfoundland Coins, Newfoundland Silver, Canadian Silver, Canadian Banknotes, 1859 Large Cent Varieties, 1926 Near 6 Nickel, and 1973 Large Bust Quarter.
- `AlertEngine`, `AlertRecord`, and `AlertScore` for on-demand alert generation.
- Alert types for watchlist matches, upgrade opportunities, collection-gap opportunities, high-priority opportunities, and rare target opportunities.
- Tools -> Watchlists & Alerts GUI workflow with editable watch rows, candidate rows, scan output, CSV export, and Markdown export.

## Architecture Highlights

- Reuses existing Deal Hunter, Deal Hunter Ranking, Live Deal Hunter, listing connector, and Market Intelligence Automation output shapes.
- Does not duplicate recommendation, ownership, upgrade, pricing, or collection intelligence logic.
- Alert scoring uses existing metadata where available: watch priority, collection relevance, opportunity score, market confidence, and upgrade or rare-target indicators.
- Exports are handled through `WatchlistReport` and `AlertReport`.

## Known Limitations

- Alerts are generated only when the user runs a scan.
- No push, email, SMS, background polling, scheduled jobs, automatic purchasing, bidding, live pricing, or collection mutation.
- Matching is deterministic text and metadata matching. Collectors should review matches before acting.
- Watchlist persistence is not a dedicated storage feature in v4.3.
