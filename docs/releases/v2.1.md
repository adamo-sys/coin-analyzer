# Coin Analyzer v2.1

Release date: 2026-06-18

Release hash: Pending tag verification

## Overview

Coin Analyzer v2.1 adds a lightweight Persistence Layer so important runtime/local state can survive application restart. It uses local JSON storage only and does not add OCR, image recognition, scraping, APIs, live pricing, market prediction, cloud sync, user accounts, or a database server.

## Major Features

- `PersistenceManager` for save, load, clear, validate, backup, import, and export.
- `AppState` model for version, saved timestamp, workbook path, WANT_LIST path/source, session metadata, market records, photo records, shopping candidates, app preferences, warnings, and errors.
- Default app-state location: `collection_data/app_state/app_state.json`.
- Timestamped backup history under `collection_data/app_state/backups/`.
- Tools menu integration:
  - Save Session State
  - Load Session State
  - Clear Session State
  - Export Session State
  - Import Session State
- Restored state is reused by Collector Home, Collection Dashboard, Collection Health Report, Smart Shopping Assistant, and related tools where appropriate.

## Backup And Safety

- Saving over an existing app-state file creates a timestamped backup first.
- Clearing saved app state also creates a backup before removing the active file.
- Imported JSON is validated before replacing the active state file.
- Missing workbook paths produce warnings instead of crashes.
- Corrupt JSON is reported cleanly.
- The persistence layer does not overwrite or modify the collection workbook.
- The persistence layer does not modify production ownership data in `data/collection.json`.

## Known Limitations

- Persistence is local JSON only.
- No cloud sync, user accounts, credentials, database server, or cross-device synchronization.
- Restoring workbook-backed context requires the referenced workbook to still exist.
- Market, photo, and shopping state is stored as app-state JSON, not as a normalized database.
- No live pricing, market prediction, OCR, image recognition, scraping, Numista expansion, or market-price APIs.
