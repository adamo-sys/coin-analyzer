# Coin Analyzer v2.5.2

## Overview

v2.5.2 adds Shopping Explainability so collectors can understand why an existing recommendation is BUY, PASS, WATCH, NEGOTIATE, or REVIEW.

This release does not add a new recommendation engine and does not change recommendation outcomes. It translates existing Smart Shopping, Listing Analyzer, Acquisition Workflow, and Acquisition Impact outputs into collector-readable explanations.

## Major Features

- `RecommendationConfidence` for deterministic High, Medium, and Low confidence labels.
- `RecommendationExplanation` for primary reasons, supporting reasons, impact summary, warnings, and collector notes.
- `ExplainableRecommendationReport` with Markdown and CSV export.
- `ShoppingExplanationEngine` for Smart Shopping recommendations, Listing Analyzer results, and Acquisition Workflow decisions.
- Smart Shopping Assistant markdown now includes compact "Why" blocks.
- Listing Analyzer GUI output now shows confidence, primary reasons, and supporting reasons.

## Explanation Model

BUY-style recommendations can explain:

- Explicit WANT_LIST target.
- Collection gap.
- Better-grade upgrade candidate.
- Positive acquisition impact.
- Asking price at or below max rational price.

PASS recommendations can explain:

- Same-grade duplicate.
- Lower-grade duplicate.
- Already owned.
- No meaningful collection impact.
- Poor asking price relative to max rational price.

WATCH, NEGOTIATE, and REVIEW recommendations can explain:

- Missing asking price.
- Price above max rational price.
- Interesting target but not decisive.
- Manual review required.
- Ambiguous classification or attribution risk.

## Confidence Levels

- High: existing engines produced a decisive recommendation with high classification confidence and no warning flags.
- Medium: recommendation is useful but has warnings, price uncertainty, negotiation/watch status, or moderate confidence.
- Low: manual review is required or classification confidence is low.

Confidence is deterministic rule output, not AI confidence.

## Known Limitations

- Explainability does not change recommendation outcomes, thresholds, prices, rankings, duplicate logic, or ownership logic.
- It can only explain data already present in existing recommendation outputs.
- It does not scrape, use live pricing, call APIs, or use AI confidence.
