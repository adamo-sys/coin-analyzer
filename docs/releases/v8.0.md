# v8.0 Release Notes — Smart Phone Cataloguer

## Overview

The Smart Phone Cataloguer enables rapid coin cataloguing directly from a phone camera or photo gallery, bridging the gap between physical discovery and digital collection management. It provides a streamlined, mobile-optimized workflow for capturing coin images, extracting metadata via OCR, identifying the coin through deterministic matching against the collection database, and cataloguing it with minimal friction.

This is **not** a mobile app. It is a desktop readiness and architecture milestone focused on:
- Desktop dependency audit and service layer boundary review
- Mobile-friendly input workflows within the existing GUI
- API readiness mapping for future mobile integration
- Phone workflow audit and optimization
- Photo capture integration with existing Photo Capture Engine and OCR Identification Engine

## Features

### Phase 1: Photo Capture Integration
- Reuse existing `photo_capture.py` Photo Capture Engine
- Add "Capture from Phone" workflow in GUI
- Support gallery import and camera capture
- Batch photo selection from phone gallery

### Phase 2: OCR Identification Integration
- Reuse existing `ocr_identification.py` OCR Identification Engine
- Extract denomination, year, country from phone-captured images
- Display OCR results with confidence scores
- Manual correction interface for OCR errors

### Phase 3: Collection Matching
- Reuse existing `collection_intelligence.py` Collection Intelligence Engine
- Match identified coins against existing collection
- Detect duplicates before cataloguing
- Suggest series gaps for new acquisitions

### Phase 4: Cataloguing Workflow
- Reuse existing `coin_collection.py` CoinCollection and CoinItem
- Minimal data entry (grade, notes, purchase info)
- Auto-populate fields from OCR + matching
- One-click "Add to Collection" with review

### Phase 5: GUI Integration
- Tools → Smart Phone Cataloguer menu item
- Mobile-friendly dialog layout (larger buttons, simplified flow)
- Photo preview, OCR results, match results, cataloguing form
- Export batch results to CSV/JSON
