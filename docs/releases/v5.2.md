# Coin Analyzer v5.2

## Overview

v5.2 adds OCR-Assisted Identification, a review-only pipeline that turns captured photos and OCR text into explainable identification candidates.

This release does not add computer vision attribution, AI grading, automatic collection entry, automatic ownership decisions, automatic purchases, or collection mutation. OCR remains advisory only and manual review remains mandatory.

## Major Features

- `ocr_assisted_identification.py` with `OCRIdentificationEngine`, `OCRIdentificationCandidate`, `OCRIdentificationReport`, and `IdentificationEvidence`.
- CapturedPhoto -> OCR Extraction -> OCR Validation -> Identification Candidate -> Review Report pipeline.
- Candidate fields for year, denomination, country, monarch, banknote prefix, certification number, series/type, silver indicator, and possible variety keywords.
- Evidence model with OCR text used, validation score, trust level, supporting keywords, conflicts detected, and missing evidence.
- HIGH/MEDIUM/LOW confidence classification with explicit reasoning.
- Collection, WANT_LIST, and watchlist context for already-owned, possible-upgrade, collection-gap, watchlist-match, and needs-review signals.
- Mobile Collector Companion OCR identification summary integration.
- Tools -> OCR-Assisted Identification GUI workflow.
- CSV and Markdown export.

## Architecture Highlights

- Reuses OCR Experiment for OCR suggestion extraction.
- Reuses OCR Validation for trust, validation score, warnings, findings, and review recommendations.
- Reuses Phone Photo Capture as the captured-photo source.
- Reuses Focused Collection Intelligence for collection context.
- Reuses Watchlists & Alerts for watchlist context.
- Keeps all outputs report-only and review-only.
