# Coin Analyzer v3.4

## Overview

Coin Analyzer v3.4 adds the Deal Hunter Ranking and Import Framework.

This release turns offline Deal Hunter analysis from single-listing review into candidate-pool ranking. Collectors can merge manual and CSV-sourced listing rows, suppress duplicate listings, and surface the strongest opportunities by overall rank, budget, and collection category.

This remains deterministic local guidance only. It does not scrape websites, use browser automation, call eBay APIs, fetch live listings, claim live market pricing accuracy, purchase automatically, recognize images, or mutate collection data.

## Major Features

- `CandidatePool` for merged manual and CSV listing pools.
- `ImportProfile` for eBay CSV, Auction CSV, Dealer CSV, and Custom CSV mappings.
- Import validation for required fields, unsupported URL formats, malformed prices, skipped rows, and warnings.
- Duplicate management for identical URLs and repeated listing imports.
- `DealHunterRankingEngine` that reuses Deal Hunter and Opportunity Engine outputs instead of duplicating recommendation logic.
- `RankingScore` from Deal Hunter score, Opportunity Engine score, collection fit, upgrade value, gap value, WANT_LIST relevance, liquidity, risk, and budget fit.
- Budget optimization for $50, $100, $250, and $500.
- Category views for top overall, under-budget, Newfoundland, Canadian silver, banknote, upgrade, collection gap, and WANT_LIST opportunities.
- Tools -> Deal Hunter Ranking GUI entry point.
- CSV and Markdown export for ranking reports.

## Known Limitations

- CSV import profiles are offline mapping frameworks only.
- URLs and image URLs remain reference data only.
- Rankings depend on supplied local candidate data and existing collection context.
- Scoring is deterministic guidance, not market appraisal or live pricing.
- Ambiguous listings still require collector review.
