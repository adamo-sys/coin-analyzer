# Coin Analyzer v2.4.2

Release date: 2026-06-18

Release hash: See verified tag `v2.4.2`

## Overview

Coin Analyzer v2.4.2 adds Collection Integrity Audit. This is a trust and validation release focused on detecting collection-data quality issues before they affect dashboards, shopping recommendations, series progress, quality scoring, acquisition impact, health reporting, or mobile companion workflows.

The audit is read-only. It reports issues and recommendations but does not modify collection records, workbooks, photos, market data, shopping candidates, app state, or backups.

## Major Changes

- `CollectionIntegrityAudit` reusable service.
- `CollectionIntegrityReport` structured output.
- `CollectionIntegrityScore` with category scores, strengths, weaknesses, and recommended actions.
- Photo, market, and certification integrity summaries.
- Tools -> Collection Integrity Audit GUI entry.
- Markdown and CSV export support.

## Audit Categories

The report checks:

- Duplicate ownership records.
- Missing dates.
- Missing grades.
- Invalid country, denomination, and year values.
- Missing, malformed, and duplicate certification references.
- Orphan photo references and missing photo files.
- Orphan market records and duplicate market observations.
- Shopping candidate photo-reference issues.
- Invalid persisted paths through existing persistence validation.
- Backup readiness through `BackupManager` and `DataSafetyValidator`.

## Known Limitations

- Duplicate detection is probable and requires collector review.
- Certification checks depend on metadata already present in collection, photo, or app-state records.
- Photo and market integrity checks validate local stored references only.
- The audit does not repair, merge, delete, normalize, or import records.
- No OCR, image recognition, scraping, APIs, live pricing, cloud sync, database server, Numista integration, or new recommendation engine was added.
