# v8.2 Release Notes — AI Grading Assistant

## Overview

AI Grading Assistant provides deterministic, explainable coin grading guidance using local collection data, grade reference patterns, and evidence-based confidence scoring. It does not perform computer vision, image recognition, or automated grading decisions. All outputs are advisory and require collector review.

## Mission

Help collectors make more informed grading decisions by comparing candidate coins against collection grade patterns, identifying likely grade ranges, flagging review-worthy cases, and explaining the reasoning behind each assessment.

## Design Principle

Favor reuse over invention. The AI Grading Assistant reuses existing Collection Intelligence, Photo Vault metadata, and OCR Identification outputs. It is an orchestration and evidence layer only — no new image processing, no new computer vision, no automated grade assignment.

## Pipeline

```
Candidate Photo / Manual Entry
   │
   ▼
Photo Vault Context (optional)
   │
   ▼
OCR Identification Evidence (optional)
   │
   ▼
Collection Grade Pattern Analysis
   │
   ▼
Grade Range Estimation
   │
   ▼
Confidence Scoring & Evidence
   │
   ▼
Review Flags & Recommendations
   │
   ▼
Graded Assessment Report
```

## Features

### Phase 1: Grade Pattern Engine
- Analyze collection grade distribution by country, denomination, series
- Identify grade patterns for owned items (e.g., "most Newfoundland 5c are VG-F")
- Flag when a candidate falls outside typical collection grade range

### Phase 2: Grade Range Estimation
- Estimate likely grade range from available evidence (OCR text, photo metadata, manual description)
- Confidence scoring based on evidence quality and collection pattern strength
- Explicit uncertainty when evidence is weak

### Phase 3: Review Flagging
- Flag cases needing manual review (unusual grade claims, conflicting evidence, rare varieties)
- Integration with existing review workflows
- Escalation to REVIEW when confidence is low

### Phase 4: Assessment Reporting
- Per-candidate assessment with grade range, confidence, evidence, and reasoning
- Batch assessment for multiple candidates
- CSV/Markdown export

### Phase 5: GUI Integration
- Tools → AI Grading Assistant menu item
- Manual candidate entry with photo reference
- Assessment display with evidence breakdown
- Batch assessment dialog

- New: `test_ai_grading_assistant.py` — comprehensive tests
- Modified: `coin_collection_gui.py` — Tools menu integration

## Guardrails
- No computer vision or image recognition
- No automated grade assignment to collection records
- All assessments are advisory-only
- No live pricing or market data
- No collection mutation
- Deterministic, testable, explainable

## Testing Strategy

- Integration tests: candidate → assessment → report
- Fixture-based tests with sample grade scenarios
- Regression: must pass alongside existing 1015+ tests
