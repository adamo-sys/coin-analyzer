# Coin Analyzer v5.0

## Overview

v5.0 adds Mobile Collector Companion, a desktop/local mobile-oriented workflow layer for fast field decisions.

This release is not a mobile app. It does not add Android development, iOS development, cloud sync, phone-camera integration, OCR identification, live fetching, purchasing, or collection mutation.

## Major Features

- `mobile_collector_companion.py` with `MobileCollectorCompanion`, `MobileSession`, `MobileWorkflow`, and `MobileCompanionReport`.
- Mobile-oriented workflows for Coin Show, Dealer Visit, Antique Market, Coin Shop, and Auction Preview situations.
- `QuickDecisionSummary` for concise BUY/WATCH/PASS/REVIEW output with confidence, top reasons, key risks, watchlist matches, collection relevance, and market intelligence summary.
- `MobileCollectionContext` for watchlist summary, active targets, collection priorities, recent opportunities, and portfolio highlights.
- `MobileDashboard` for active watchlists, high-priority targets, recent alerts, recent opportunities, collection priorities, and quick decisions.
- `FieldWorkMode` for short-form on-the-go summaries.
- Tools -> Mobile Collector Companion GUI workflow.
- CSV and Markdown export.

## Architecture Highlights

- Reuses Deal Hunter Ranking, Market Intelligence Automation, Watchlists, Alerts, Portfolio Performance, and Field Test Framework.
- Does not duplicate ownership, duplicate, upgrade, opportunity, market, watchlist, or recommendation logic.
- Keeps mobile-specific concepts as workflow and reporting models that future phone/photo/OCR features can consume.

## Known Limitations

- Desktop/local mobile workflow simulation only.
- No Android app, iOS app, web app, cloud sync, phone-camera integration, OCR identification, live fetching, purchasing, or collection mutation.
- Quick decisions are compact summaries of existing deterministic engines and should be manually reviewed before purchases.
