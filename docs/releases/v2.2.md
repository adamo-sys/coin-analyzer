# Coin Analyzer v2.2

Release date: 2026-06-18

Release hash: `d84aa40334a6c3f859a996006bfe8005074ea6a4`

## Overview

Coin Analyzer v2.2 adds Data Safety and Backup Hardening. The release focuses on making local app data easier to validate, back up, verify, and restore safely without adding cloud sync, live pricing, scraping, OCR, image recognition, external APIs, user accounts, or a database server.

## Major Features

- `BackupManager` for local backup package creation, verification, listing, metadata reports, restore, and export bundles.
- `BackupManifest` with included files, excluded files, missing files, warnings, restore notes, sizes, and SHA-256 checksums.
- `DataSafetyValidator` and `DataSafetyReport` for PASS/WARNING/FAIL validation.
- Tools menu entries:
  - Data Safety Check
  - Create Backup Package
  - List Backups
  - Restore Backup
- Collector Export Bundle with Collection Health Report, Shopping recommendations, Market Awareness summary, Series summary, Photo coverage summary, CSV index, and manifest.

## Backup Package Contents

Packages include safe local project/app files when available:

- App state JSON
- Market records stored inside app state
- Photo records stored inside app state
- Shopping candidates stored inside app state
- Release history
- Release notes
- Backup manifest JSON
- Backup manifest Markdown

Collection workbooks are not copied automatically. Keep workbook backups separately unless explicitly and intentionally included in a future workflow.

## Restore Safety

- Backup packages are verified before restore.
- Restore creates a pre-restore backup first.
- Restore reports restored files and skipped files.
- Restore writes known safe app-state paths by default.
- Restore does not modify collection workbooks.
- Restore does not mutate production collection ownership data.

## Known Limitations

- Backup packages are local zip files only and do not replace off-machine backups.
- No cloud sync, user accounts, credentials, database server, live pricing, market prediction, OCR, image recognition, scraping, APIs, or Numista expansion.
- Collection workbook backup remains a separate intentional user action.
- Restore is deliberately conservative and focuses on known safe app-state files.
