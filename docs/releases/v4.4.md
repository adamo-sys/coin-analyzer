# Coin Analyzer v4.4

## Overview

v4.4 adds Live Deal Hunter Field Test & Tuning so the live opportunity pipeline can be measured with deterministic realistic scenarios before expanding into mobile workflows.

This is a tuning and hardening release. It does not add live sources, scraping, browser automation, API integrations, automatic purchasing, collection mutation, push notifications, or cloud sync.

## Major Features

- `field_test_framework.py` with `FieldTestScenario`, `FieldTestResult`, `FieldTestReport`, and `ScenarioRunner`.
- Deterministic scenario library covering Newfoundland upgrade, Newfoundland duplicate, 1859 variety candidate, 1926 Near 6 candidate, Canadian silver lot, banknote opportunity, high shipping trap, non-CAD listing, weak title listing, duplicate URL listing, false-positive watchlist match, and strong watchlist match.
- `OpportunityQualityReport` for recommendation distribution, review escalation frequency, and confidence distribution.
- `PipelineHealthReport` for listings processed, validation failures, duplicates, watchlist matches, alerts generated, review escalations, accepted listings, and rejected listings.
- `FalsePositiveAudit` for duplicate misclassification risk, weak watchlist matches, weak keyword matches, weak upgrade signals, and noisy low-score alerts.
- Tools -> Field Test & Tuning GUI workflow.
- CSV and Markdown export for field-test reports and supporting reports.

## Architecture Highlights

- Reuses existing Live Source Validation, Live Deal Hunter, Deal Hunter Ranking, Market Intelligence Automation, Watchlists, and Alerts.
- Runs deterministic `LiveListingBatch` fixtures locally with no network dependency.
- Preserves existing recommendation engines and reports; v4.4 observes and audits pipeline behavior rather than replacing scoring.
- Watchlist confidence is reduced when candidate text contains obvious souvenir/token/copy/replica wording, making false-positive collector targets easier to review.

## Known Limitations

- Field tests use deterministic local fixtures only.
- No live network source is fetched by the field-test framework.
- Findings are review recommendations only; the framework does not automatically rewrite scores, watches, source validation, recommendations, or collection data.
- No scraping, browser automation, APIs, automatic purchasing, collection mutation, push notifications, or cloud sync.
