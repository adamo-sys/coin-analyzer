# Coin Analyzer v2.5.1

## Overview

v2.5.1 hardens Photo Vault reliability with a read-only integrity audit and coverage report.

This release does not add OCR, image recognition, AI grading, scraping, APIs, live pricing, cloud sync, database servers, or Numista integration. It reports photo metadata issues only.

## Major Features

- `PhotoVaultIntegrityAudit` for metadata trust checks.
- `PhotoCoverageReport` for coverage metrics and exportable findings.
- `PhotoVaultIssue` for structured missing, duplicate, unlinked, invalid, and unsupported photo metadata findings.
- Tools -> Photo Vault Audit GUI report.
- Markdown and CSV export for Photo Vault audit output.
- Data Safety validation integration for photo metadata warnings.
- Collection Recovery Report messaging that photo metadata is backed up in app state while photo files are not copied automatically.

## Audit Checks

- Missing photo files.
- Invalid photo paths.
- Duplicate photo references.
- Unlinked photo records.
- Collection items without photos.
- Candidate records without photos.
- Certified/slabbed items without photos.
- Invalid image extensions.
- Unsupported URL-style photo paths.

## Coverage Metrics

- Total photo records.
- Valid photo references.
- Missing photo references.
- Duplicate photo references.
- Collection photo coverage percentage.
- Certified-item photo coverage percentage.
- Candidate photo coverage percentage.

## Backup and Recovery

- Backup packages preserve Photo Vault metadata stored in app state.
- Backup packages preserve Photo-Assisted Entry candidate metadata stored in app state.
- Photo files themselves are not copied automatically.
- Keep `coin_photos/` folders in regular external backups.

## Known Limitations

- The audit does not inspect image contents.
- The audit does not repair, move, delete, rename, classify, OCR, or grade files.
- Valid reference count only confirms path existence, not image quality.
- Candidate coverage depends on available photo candidate metadata in app state.
