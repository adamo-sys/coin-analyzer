# Coin Analyzer v2.6

## Overview

v2.6 adds OCR Experiments, a safe advisory workflow for running OCR against collector-supplied photos and reviewing extracted text suggestions.

This release is experimental. OCR output remains review-only and never modifies collection ownership data, grades, recommendations, shopping rankings, or acquisition decisions.

## Major Features

- `OCRResult` for raw OCR text, source image path, engine metadata, timestamp, and warnings.
- `OCRConfidence` for deterministic High, Medium, and Low confidence labels.
- `OCRSuggestionReport` for possible years, denominations, countries, note prefixes, certification numbers, warnings, manual-review status, and CSV/Markdown export.
- `OCRExperiment` for optional local OCR execution and deterministic raw-text suggestion extraction.
- Tools -> OCR Experiment desktop workflow.
- App-state persistence for OCR results and reports.
- Helper integrations for Photo-Assisted Entry, Photo Vault photo records, and Mobile Companion candidates.

## Advisory-Only Guardrails

OCR Experiments do not:

- Modify `data/collection.json`.
- Create collection records.
- Update ownership records.
- Grade coins or banknotes.
- Change recommendations, shopping ranks, or purchase decisions.
- Scrape websites, call pricing APIs, or identify coins by image.

Manual review is always required.

## Known Limitations

- Local OCR depends on the user's installed OCR runtime; if unavailable, the workflow reports a warning and continues safely.
- OCR suggestions are deterministic text parsing, not attribution proof.
- Ambiguous or incomplete OCR text must be manually verified.
- App-state backups preserve OCR metadata, not arbitrary photo folders.
