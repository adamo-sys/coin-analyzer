# Coin Analyzer v2.4.1

Release date: 2026-06-18

Release hash: See verified tag `v2.4.1`

## Overview

Coin Analyzer v2.4.1 is a critical collection-data safety patch. It closes the backup gap where local backup packages protected app-state data but did not automatically protect the production ownership file or the persisted collection workbook path.

## Major Changes

- Backup packages include `data/collection.json` by default when available.
- Backup packages copy the persisted collection workbook path when available and readable.
- Workbook backup is copy-only. The workbook is never edited, overwritten, or mutated.
- Backup manifests now report:
  - `collection_json_backed_up`
  - `workbook_backed_up`
  - `app_state_backed_up`
  - missing files
  - warnings
- Collection Recovery Report summarizes recoverable and not-recoverable collection data.
- Data Safety Check validates collection JSON existence, latest backup coverage, workbook path availability, and workbook backup availability.
- Tools menu includes Collection Recovery Report.

## Recovery Coverage

The new recovery report can identify whether these records are recoverable from the latest verified backup:

- `data/collection.json` ownership records
- Collection workbook copy
- App state
- Market Awareness records stored in app state
- Photo Vault metadata stored in app state
- Smart Shopping candidates stored in app state

## Known Limitations

- Backup packages are local zip files only and do not replace off-machine backups.
- Workbook copy coverage depends on a saved app-state workbook path.
- If the workbook path is stale or missing, backup continues and reports a warning.
- No cloud sync, remote backup service, database server, OCR, image recognition, scraping, live pricing, or external API was added.
