# v7.2 Collection Insights

**Release Date:** 2026-06-25  
**Version:** v7.2  
**Status:** Released  

## Scope

v7.2 Collection Insights transforms deterministic platform analytics into explainable, evidence-based observations about the collection, portfolio, workflow, and acquisition strategy. This release provides collectors with actionable insights derived entirely from local collection data without AI reasoning, forecasting, machine learning, or external APIs.

## Implemented Features

### Collection Insights Engine (`collection_insights.py`)

**Core Data Structures:**
- `InsightCategory`: Enum for insight categories (collection, portfolio, acquisition, workflow, health)
- `InsightPriority`: Enum for priority levels (critical, high, medium, low, informational)
- `InsightEvidence`: Supporting evidence for insights with metric name, value, description, and timestamp
- `CollectionInsight`: Single insight with category, priority, title, description, explanation, evidence, affected modules, confidence, and actionability
- `CollectorHealthReport`: Comprehensive health report with overall score and component scores
- `CollectionInsightReport`: Complete insights report with categorized insights and health report
- `InsightsDashboard`: Dashboard with summary, priority counts, and category breakdown

**CollectionInsightsEngine:**
- `generate_insights()`: Generate complete collection insights report from local data
- `_generate_collection_insights()`: Insights about collection growth, composition, diversity, grade coverage, year span
- `_generate_portfolio_insights()`: Insights about portfolio value, unrealized gain/loss, silver exposure
- `_generate_acquisition_insights()`: Insights about watchlist progress, duplicate concentration
- `_generate_workflow_insights()`: Insights about workflow completion rate, photo coverage, OCR utilization
- `_generate_health_report()`: Comprehensive health report with metadata, photo, OCR, grading, and workflow scores
- `_prioritize_insights()`: Prioritize insights by priority and confidence
- `generate_dashboard()`: Generate insights dashboard with summary and breakdowns
- `export_report_markdown()`: Export insights report as Markdown
- `export_report_csv()`: Export insights report as CSV
- `export_health_markdown()`: Export health report as Markdown
- `export_health_csv()`: Export health report as CSV

## Guardrails

**Strictly Followed:**
- No AI reasoning, forecasting, or machine learning
- No external APIs or web services
- All insights are deterministic and explainable
- All insights derive from local collection data only
- Confidence scores based on data completeness, not AI certainty
- No automatic collection mutations
- No automatic purchasing or bidding
- No background jobs

**Design Principles:**
- Insights are evidence-based with supporting metrics
- Insights are actionable with clear explanations
- Insights are prioritized by importance and confidence
- Health scores are weighted averages of measurable components
- Export formats support both human-readable (Markdown) and machine-readable (CSV)

## Known Limitations

- Collection Insights currently uses placeholder data for portfolio value, acquisition cost, and silver value
- Workflow data (completed workflows, workflow sessions) is not fully integrated with actual workflow engine state
- Watchlist integration is basic and does not track actual watchlist progress
- Health scores are based on available data fields and may not reflect all aspects of collection health
- Insights are generated on-demand and do not track trends over time (trend analysis is a future enhancement)
