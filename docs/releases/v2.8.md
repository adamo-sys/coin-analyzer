# Coin Analyzer v2.8

## Overview

v2.8 adds the Collector Home Dashboard, a unified daily dashboard that answers:

- What needs attention?
- What is safe?
- What should be reviewed?
- What opportunity matters most?
- What progress has been made?

This is a workflow-surfacing release. It does not add recommendation engines, OCR capabilities, image recognition, grading, scraping, APIs, live pricing, cloud sync, database servers, background jobs, or automatic collection mutation.

## Major Features

- `CollectorHomeDashboard` for aggregating existing collector status into one report.
- `CollectorHomeReport` for a concise home report with headline, status cards, actions, warnings, opportunities, progress, and workflow statuses.
- `HomeStatusCard` sections:
  - Collection Health
  - Acquisition Focus
  - Review Queue
  - Data Safety
  - Progress
- `DailyCollectorAction` ranking by deterministic severity and urgency.
- `HomeStatusSeverity` values: `OK`, `INFO`, `WARNING`, and `ACTION_REQUIRED`.
- Tools -> Collector Home Dashboard.
- Local app-state persistence for generated home reports and acknowledged action identifiers.
- CSV and Markdown export.

## Architecture Highlights

Collector Home Dashboard reuses existing systems:

- Collection Dashboard
- Collection Quality Engine
- Collection Integrity Audit
- Smart Shopping Assistant
- Shopping Explainability and Acquisition Impact through shopping output
- OCR Validation Layer
- Photo Vault Audit
- BackupManager and DataSafetyValidator
- Collection Snapshot System
- Series Tracker
- Collector Workflow Engine and Daily Collector Summary
- Persistence Layer

It does not duplicate ownership, duplicate, upgrade, OCR, validation, shopping, quality, integrity, backup, snapshot, series, or photo-audit logic.

## Known Limitations

- The dashboard is local and text/table based.
- Acknowledged action storage is lightweight and not a task-management system.
- Snapshot trend reporting depends on existing saved snapshots.
- Data Safety status depends on local backup and app-state files.
- GUI automation remains limited by the local Tcl/Tk environment.
