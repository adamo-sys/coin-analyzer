# v7.5 Release Notes — Numista Intelligence

## Overview

Numista Intelligence provides deterministic, offline analysis of Numista export data to identify collection gaps, duplicates, upgrade opportunities, variety targets, and new series opportunities without live API calls, web scraping, or external services.

## Features

- **NumistaDataModel**: Parse and normalize Numista Excel/CSV exports with field mapping, validation, and error reporting.
- **NumistaCollectionAnalyzer**: Compare Numista items against local collection using N# matching, country/year/reference signature matching, grade comparison, series relevance detection, and variety indicators.
- **NumistaIntelligenceEngine**: Orchestrates data loading, analysis, and report generation with CSV and Markdown export support.
- **NumistaIntelligenceReport**: Comprehensive report with owned, duplicate, upgrade, gap, variety, new series, and not-relevant classifications.
- **GUI Integration**: Tools -> Numista Intelligence dialog for file selection, analysis display, CSV export, and Markdown export.
- **Factory Support**: `NumistaIntelligenceEngine.from_items()` builds engine from raw collection items without fabricating full CoinCollection objects.

## Limitations

- Deterministic local guidance only; no live Numista API, web scraping, or external services.
- Series matching covers Newfoundland and Canadian silver priorities; other collecting areas may need expansion.
- Grade comparison uses standard grade ordering (AG through MS70); non-standard grades may need manual review.
- Numista export must be in expected Excel/CSV format with standard Numista columns.
- GUI integration is minimal; no batch processing or advanced filtering.
