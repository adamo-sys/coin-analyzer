# Coin Analyzer v3.9

## Overview

Coin Analyzer v3.9 adds Portfolio Performance: deterministic local reporting for collection growth, progress, health, and focus areas.

This release is not investment advice. It does not add live pricing, scraping, APIs, market forecasting, automatic purchasing, or collection mutation.

## Major Features

- `PortfolioPerformanceEngine` for portfolio-level collection-development reporting.
- `CollectionGrowthReport` for collection size, local estimated value, silver holdings, slab count, banknote count, Newfoundland count, custom category counts, and snapshot comparison.
- `AcquisitionPerformanceReport` for best acquisitions, biggest upgrades, highest collection impact, strongest opportunity captures, and highest-confidence purchases.
- `SeriesProgressReport` for completion percentages, progress since last snapshot, nearest completions, neglected series, and strongest-performing series.
- `BudgetAllocationReport` for Newfoundland, Canadian silver, banknotes, slabs, upgrades, duplicates, and other categories.
- `CollectionHealthScore` for backup readiness, collection integrity, photo coverage, documentation/certification coverage, duplicate control, WANT_LIST alignment, snapshot coverage, and series progress.
- `PortfolioPerformanceReport` executive dashboard with strengths, weaknesses, opportunities, risks, and recommended focus areas.
- Tools -> Portfolio Performance GUI workflow.
- CSV and Markdown export.

## Architecture Highlights

Portfolio Performance reuses existing systems:

- Collection Snapshot System for current/previous/first comparison.
- Collection Intelligence for duplicate and upgrade context.
- Opportunity Engine for acquisition opportunity context.
- Market Intelligence context and local Market Awareness records for local-only purchase/acquisition context.
- Series Tracker for completion and neglected-series reporting.
- Collection Quality and Collection Integrity for health scoring.

## Known Limitations

- Portfolio Performance uses only local records, snapshots, and existing deterministic engines.
- Local estimated value comes from collection records already available in the app.
- Snapshot comparisons are limited until prior snapshots exist.
- The report does not forecast future value, claim live market pricing, or provide investment advice.
