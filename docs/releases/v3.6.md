# Coin Analyzer v3.6

## Overview

Coin Analyzer v3.6 adds Deal Hunter Calibration, an offline quality-control layer for testing Deal Hunter and Deal Hunter Ranking behavior against realistic collector-judgment cases before any live-source ingestion work begins.

This release improves decision trust. It helps identify false BUYs, false PASSes, false REVIEWs, ranking misses, missing risk flags, and explanation gaps using deterministic local fixtures.

## Major Features

- Added `DealHunterCalibrationEngine` for comparing expected collector judgment against actual Deal Hunter and Ranking output.
- Added `CalibrationCase` fixtures with expected recommendation, rank category, risk flags, rationale, and collector notes.
- Added `DealHunterCalibrationReport` with passed/failed case counts, false recommendation buckets, ranking misses, missing risk flags, over-penalized and under-penalized cases, and tuning notes.
- Added Tools -> Deal Hunter Calibration with default fixture loading, CSV loading, summary display, and CSV/Markdown export.
- Added offline calibration fixture data under `test_data/deal_hunter/calibration_cases.csv`.
- Tuned raw high-grade risk detection so raw AU/MS-style listing titles receive raw-overgraded manual-review handling.

## Calibration Coverage

The v3.6 fixture set covers:

- obvious BUY
- obvious PASS
- good item weakened by shipping
- cool but irrelevant item
- Newfoundland upgrade
- banknote target
- chartered banknote target
- same-grade duplicate
- lower-grade duplicate
- raw overgraded coin
- damaged/problem coin
- vague estate lot
- bulk lot requiring review
- unclear currency
- explicit WANT_LIST match

## Known Limitations

- Calibration cases are offline fixtures, not live market data.
- Calibration does not fetch listings, scrape websites, call APIs, or validate real-time prices.
- Expected outcomes are deterministic collector-judgment examples and should be reviewed as collecting priorities evolve.
- Raw-overgraded detection is text-signal based; ambiguous listings still require manual review.

## Guardrails

v3.6 does not add:

- scraping
- browser automation
- eBay APIs
- dealer APIs
- auction APIs
- live listing retrieval
- live pricing
- automatic purchasing
- image recognition
- collection mutation
