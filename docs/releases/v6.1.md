# Coin Analyzer v6.1

## Overview

v6.1 adds Sync & Backup, an offline disaster-recovery and sync-planning layer on top of v6.0 Collector Cloud Foundation. It creates backup archives, restore plans, backup history, synchronization simulations, conflict reports, and rollback plans entirely locally.

This release is not internet synchronization, cloud providers, user accounts, authentication, automatic conflict resolution, automatic restore, background sync, or collection mutation.

## Major Features

- `sync_backup_engine.py` with `SyncBackupEngine`, `BackupArchive`, `RestorePlan`, `BackupHistory`, `SyncSimulation`, `SyncConflictReport`, and `RollbackPlan`.
- Backup archives for collection, portfolio, watchlists, workflow, and settings scope with timestamp, version, source snapshot, checksum, metadata, record count, and warnings.
- Restore planning with affected modules, affected records, validation results, warnings, conflicts, and rollback options.
- Backup history with archive timeline, snapshot comparisons, collection deltas, portfolio deltas, and workflow deltas.
- Sync simulation for local Device A Snapshot -> Device B Snapshot -> Sync Proposal -> Conflict Analysis -> Merge Preview.
- Conflict reports for duplicate entries, collection mismatches, workflow mismatches, settings mismatches, snapshot divergence, and backup incompatibilities.
- Rollback plans for backup, restore, and sync scenarios with rollback targets, scope, risks, and recommendations.
- Tools -> Sync & Backup GUI workflow.
- CSV and Markdown export for BackupArchive, RestorePlan, BackupHistory, SyncSimulation, SyncConflictReport, and RollbackPlan.

## Architecture Highlights

- Reuses Collector Cloud Foundation snapshots and sync-plan comparison logic.
- Reuses Collector Workflow Integration and Mobile Collection Entry report records through Collector Cloud snapshots.
- Reuses Portfolio Performance and Collection Intelligence metrics through the underlying cloud snapshot model.
- Keeps all recovery and sync artifacts preview-only, deterministic, exportable, and side-effect-free.

## Rationale

v6.0 established the cloud architecture layer with CollectorCloud, CloudCollectionSnapshot, CloudSyncPlan, CloudBackupPackage, and CloudReadinessReport. v6.1 adds the offline backup, restore planning, snapshot history, rollback planning, and synchronization simulation layer needed before multi-device workspace work.
