# Coin Analyzer v6.1

## Overview

v6.1 begins the Sync & Backup release line. This release adds offline disaster-recovery and sync-planning capabilities on top of the v6.0 Collector Cloud Foundation.

This release is not internet synchronization, cloud providers, user accounts, authentication, automatic conflict resolution, or automatic restore. Everything remains offline and local.

## Locked Roadmap

- `v6.1` Sync & Backup
- `v6.2` Multi-Device Collector Workspace
- `v6.3` Device Linking & Conflict Resolution
- `v7.0` Collector Platform

## Rationale

v6.0 established the cloud architecture layer with CollectorCloud, CloudCollectionSnapshot, CloudSyncPlan, CloudBackupPackage, and CloudReadinessReport. The next step is implementing backup, restore planning, snapshot history, rollback planning, and synchronization simulation.

## Planned Scope

- Offline backup archives for collection, portfolio, watchlists, workflow, and settings.
- Restore planning with affected modules, affected records, validation results, warnings, conflicts, and rollback options.
- Backup history with timeline, snapshot history, comparisons, and deltas.
- Synchronization simulation between two local snapshots.
- Conflict reports for duplicates, mismatches, snapshot divergence, and backup incompatibilities.
- Rollback planning for backup, restore, and sync scenarios.
- GUI entry point: Tools -> Sync & Backup.
- CSV and Markdown export support.
