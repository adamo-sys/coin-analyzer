# Coin Analyzer v3.5

## Overview

Coin Analyzer v3.5 adds External Listing Connectors.

This release creates a local connector framework for normalizing user-supplied listing files from multiple offline sources into a common listing model that can feed Deal Hunter, Opportunity Engine, and Deal Hunter Ranking.

This remains deterministic local workflow support only. It does not scrape websites, use browser automation, call eBay/dealer/auction APIs, fetch live listings, claim live market pricing accuracy, purchase automatically, recognize images, or mutate collection data.

## Major Features

- `NormalizedListing` model with title, description, price, shipping, total cost, seller, source, source type, URL, image URL, import timestamp, and connector name.
- `ListingConnector` base class for local-file connector adapters.
- `ConnectorRegistry` for connector discovery and single-file, multi-file, and mixed-source imports.
- Built-in connectors:
  - eBay CSV Connector
  - Auction CSV Connector
  - Dealer Inventory Connector
  - Generic CSV Connector
- `ConnectorValidationReport` for required fields, malformed prices, malformed URLs, missing titles, unsupported columns, skipped rows, and import warnings.
- `ConnectorImportReport` for normalized listing import summaries.
- `SourceSummaryReport` for source, source type, and connector traceability.
- `DuplicateOpportunityDetector` for identical URLs, repeated listings, and likely duplicate opportunities across sources.
- Multi-source CandidatePool and Deal Hunter Ranking compatibility.
- Tools -> External Listing Connectors GUI workflow.
- CSV and Markdown export.

## Known Limitations

- Connectors consume local CSV files supplied by the user.
- Connectors are not scrapers and do not fetch URLs.
- Source validation is structural and deterministic; collector review is still required.
- Duplicate-opportunity detection flags likely overlaps but does not automatically delete or merge records.
- Multi-source ranking depends on supplied local data and existing collection context.
