# Coin Analyzer v2.7

## Overview

v2.7 adds Workflow Integration so existing modules behave more like guided collector workflows instead of disconnected tools.

This is an orchestration release. It does not add new recommendation logic, OCR improvements, grading systems, image recognition, scraping, APIs, live pricing, cloud sync, database servers, or automatic collection updates.

## Major Features

- `CollectorWorkflowEngine` for coordinating guided collector workflows.
- `AcquisitionWorkflow` for Photo -> Photo-Assisted Entry -> OCR Experiment -> OCR Validation -> Smart Shopping -> Shopping Explainability -> Save Candidate review.
- `CollectionReviewWorkflow` for Collection Dashboard -> Collection Quality -> Collection Integrity -> Snapshot Review -> Recommended Actions.
- `PhotoReviewWorkflow` for Photo Vault -> Photo Vault Audit -> Coverage Review -> Missing Photo Actions.
- `CollectorDailySummary` for answering "What should I do today?"
- `WorkflowStatus` and `WorkflowSummary` for lightweight status tracking and persistence.
- Tools -> Acquisition Workflow.
- Tools -> Collection Review Workflow.
- Tools -> Daily Collector Summary.
- CSV and Markdown export for workflow reports.

## Architecture Highlights

Workflow Integration reuses:

- Photo-Assisted Entry
- OCR Experiments
- OCR Validation Layer
- Smart Shopping Assistant
- Shopping Explainability
- Collection Dashboard
- Collection Quality Engine
- Collection Integrity Audit
- Collection Snapshot System
- Photo Vault Audit
- Persistence Layer

It does not duplicate ownership, duplicate, upgrade, OCR, validation, shopping, quality, integrity, snapshot, or photo-audit logic.

## Known Limitations

- Workflows are local desktop workflows, not background jobs.
- Workflow state is lightweight status/summary data only.
- Acquisition Workflow still requires collector review before saving or acting.
- Collection Review Workflow creates a current snapshot report for review but does not automatically save a snapshot.
- GUI automation remains limited by the local Tcl/Tk environment.
