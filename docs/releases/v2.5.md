# Coin Analyzer v2.5

## Overview

v2.5 adds Photo-Assisted Entry, a metadata-only workflow for attaching front, reverse, and reference photo paths to candidate acquisitions before manual review.

This is not OCR, image recognition, AI grading, scraping, live pricing, cloud sync, or a mobile app. Photos are evidence and reference material only.

## Major Features

- `PhotoCandidate` for manual candidate details plus front, reverse, and reference photo paths.
- `PhotoAssistedEntry` workflow for photo reference -> candidate entry -> manual review -> existing recommendation engines.
- `PhotoReviewReport` with attached photos, candidate details, recommendation context, warnings, and CSV/Markdown export.
- Tools -> Photo-Assisted Entry desktop workflow.
- Photo Vault candidate/reference linking without duplicating photo storage.
- Mobile Companion integration for concise recommendation output.
- Persistence Layer support for photo candidate metadata.
- Backup compatibility through app-state metadata only.

## Architecture Highlights

- Reuses `PhotoVault` for metadata-only photo records.
- Reuses `MobileCompanionWorkflow` for candidate recommendation output.
- Reuses existing acquisition, impact, WANT_LIST, and shopping logic indirectly through Mobile Companion.
- Extends `AppState` with `photo_candidates` while preserving existing app-state JSON behavior.
- Does not modify `data/collection.json`.
- Does not move, copy, read, OCR, classify, or grade photo files.

## Known Limitations

- Photo paths are stored as local references only.
- Missing photo files are reported as warnings.
- Backup packages preserve photo candidate metadata but do not copy arbitrary photo folders.
- The GUI remains a lightweight desktop workflow, not a mobile UI.
- No OCR, image recognition, AI grading, scraping, live pricing, or Numista integration is included.
