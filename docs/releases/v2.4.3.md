# Coin Analyzer v2.4.3

Release date: 2026-06-18

Release hash: See verified tag `v2.4.3`

## Overview

Coin Analyzer v2.4.3 adds the Collection Snapshot System. This reporting release lets a collector compare collection state over time and answer what changed, what improved, what got worse, and how the collection evolved.

The snapshot system is historical and read-only. It does not modify collection records, change recommendation thresholds, forecast trends, scrape data, or call external services.

## Major Changes

- `CollectionSnapshot` point-in-time data model.
- `CollectionSnapshotManager` for creating, saving, loading, and comparing snapshots.
- `CollectionSnapshotReport` for current/previous/first snapshot comparison.
- `GrowthSummary` for growth since previous and first snapshot.
- `SeriesProgressDelta` for supported-series completion changes.
- Tools -> Create Snapshot.
- Tools -> Snapshot Report.
- Markdown and CSV export support.

## Stored Metrics

Each snapshot stores:

- Snapshot timestamp.
- Collection size.
- Quality score.
- Integrity score.
- Photo coverage percentage.
- Supported-series completion metrics.
- Market record count.
- Shopping candidate count.

Snapshots are stored at:

- `collection_data/app_state/collection_snapshots.json`

Backup packages include this file when snapshots exist.

## Report Output

Snapshot Report shows:

- Current snapshot.
- Previous snapshot.
- Owned item growth since previous snapshot.
- Owned item growth since first snapshot.
- Quality score delta.
- Integrity score delta.
- Photo coverage delta.
- Series completion deltas.
- Newly completed supported series when detected.

## Known Limitations

- Snapshots compare stored local metrics only.
- No forecasting, live pricing, scraping, APIs, OCR, image recognition, cloud sync, database server, Numista integration, or new recommendation engine was added.
- Series deltas depend on supported `SeriesTracker` definitions.
- Snapshot Report does not repair or mutate collection data.
