# v6.2 Multi-Device Collector Workspace

Status: in development.

## Scope

v6.2 models how a collector uses desktop, laptop, phone, and tablet workflows while staying completely offline.

Planned architecture:

- `multi_device_workspace.py`
- `MultiDeviceWorkspaceEngine`
- `CollectorWorkspace`
- `DeviceProfile`
- `WorkspaceSnapshot`
- `WorkspaceActivity`
- `WorkspaceHealthReport`

The release builds on v6.0 Collector Cloud Foundation and v6.1 Sync & Backup. It is intended to add workspace, device, capability, activity, snapshot, and health-report models without real synchronization.

## Roadmap

- `v6.2` Multi-Device Collector Workspace
- `v6.3` Device Linking & Conflict Resolution
- `v7.0` Collector Platform

## Guardrails

v6.2 is offline architecture only. It does not add real synchronization, accounts, authentication, internet services, cloud providers, automatic restore, automatic conflict resolution, background sync, or collection mutation.
