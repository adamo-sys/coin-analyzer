# Coin Analyzer v6.0

## Overview

v6.0 begins the Collector Cloud Foundation release line. This release prepares the local Collector Companion architecture for future synchronization, backup, and multi-device operation without adding real cloud hosting, accounts, authentication, internet connectivity, cloud providers, or background sync.

## Locked Roadmap

- `v6.0` Collector Cloud Foundation
- `v6.1` Sync & Backup
- `v6.2` Multi-Device Collector Workspace
- `v6.3` Device Linking & Conflict Resolution
- `v7.0` Collector Platform

## Rationale

v5.x completed Mobile Companion, Phone Photo Capture, OCR-Assisted Identification, Mobile Collection Entry, and Collector Workflow Integration. The collector workflow is now complete. The next stage is preparing the platform for future synchronization and multi-device operation.

## Planned Scope

- Offline cloud-state model for future cloud-ready collection records.
- Collection snapshots with metadata, comparison, and history.
- Sync planning only, with proposed changes, merge candidates, and conflicts.
- Backup package modeling, validation, metadata, and restore previews.
- Conflict model with record, collection, workflow, and settings conflict types.
- Cloud readiness reporting for syncable modules, non-syncable modules, migration requirements, risks, and conflict exposure.
- GUI entry point: Tools -> Collector Cloud Foundation.
- CSV and Markdown export support.
