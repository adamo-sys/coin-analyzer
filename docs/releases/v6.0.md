# Coin Analyzer v6.0

## Overview

v6.0 adds Collector Cloud Foundation, an offline architecture layer for future synchronization, backup, recovery, and multi-device releases. It represents future cloud state locally only.

This release does not add real cloud hosting, accounts, authentication, internet connectivity, cloud providers, background synchronization, automatic restore, or collection mutation.

## Major Features

- `collector_cloud.py` with `CollectorCloud`, `CloudRecord`, `CloudCollectionSnapshot`, `CloudSyncPlan`, `CloudBackupPackage`, `CloudConflict`, and `CloudReadinessReport`.
- Cloud records with module ownership, record type, stable content hashes, update timestamps, sync status, summaries, and metadata.
- Collection snapshots with snapshot id, source label, timestamp, collection metrics, portfolio metrics, workflow metrics, module counts, content hash, metadata, warnings, and snapshot history.
- Snapshot comparison for added, removed, and changed records.
- Sync planning with source/destination snapshots, proposed changes, merge candidates, conflicts, and review-only warnings.
- Backup package model with package metadata, validation findings, restore previews, snapshot hashes, and no cloud storage or restore execution.
- Conflict model covering record, collection, workflow, and settings conflicts with manual-review recommendations.
- Cloud readiness report for syncable modules, non-syncable modules, migration requirements, risk areas, and conflict exposure.
- Tools -> Collector Cloud Foundation GUI with snapshots, sync plans, backup packages, readiness reports, conflict previews, and CSV/Markdown export.
- Mobile Collector Companion readiness-summary integration.

## Architecture Highlights

- Reuses Collection Intelligence for duplicate and upgrade metrics.
- Reuses Portfolio Performance for health, local value, silver, Newfoundland, and focus-area metrics.
- Reuses Mobile Collection Entry and Collector Workflow Integration reports as review-only cloud records.
- Keeps all future-sync artifacts local, deterministic, exportable, and side-effect-free.
