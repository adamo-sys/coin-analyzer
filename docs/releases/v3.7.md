# Coin Analyzer v3.7

## Overview

Coin Analyzer v3.7 adds Live Deal Hunter Readiness, a safety and architecture milestone that prepares the offline Deal Hunter stack for future live listing ingestion without adding live ingestion yet.

The release defines future contracts, validation rules, staleness handling, rate-limit planning, failure models, and readiness reporting while preserving the no-live-fetch boundary.

## Major Features

- Added `LiveDealHunterReadinessAudit` and `LiveDealHunterReadinessReport`.
- Added future contract models: `LiveListingSource`, `LiveListingBatch`, and `LiveListingFetchResult`.
- Added `LiveSourceValidationReport` for validating future source output before ranking.
- Added deterministic staleness flags: `FRESH`, `STALE`, and `UNKNOWN`.
- Added `RateLimitPolicy` planning model.
- Added `LiveSourceFailure` failure model.
- Added Tools -> Live Deal Hunter Readiness.
- Added CSV and Markdown exports.

## Validation Coverage

Future live-source batches can be checked for:

- missing title
- missing price
- missing shipping
- non-CAD currency
- stale listing timestamps
- duplicate URLs
- malformed URLs
- malformed image URLs
- missing seller
- suspicious raw metadata

## Safety Rules

v3.7 documents and enforces these readiness expectations:

- no automatic purchasing
- no automatic collection mutation
- no hidden network calls
- future fetches must be explicit and user-triggered
- source-specific rate-limit awareness is required
- failures must be reported clearly
- stale listing warnings are required
- currency validation is required
- shipping must be included in total cost

## Known Limitations

- No real live sources are implemented.
- `LiveListingSource.fetch_listings()` intentionally raises `NotImplementedError`.
- Rate-limit policies are planning models only; there is no scheduler or background fetch system.
- Validation works on supplied batch data only.

## Guardrails

v3.7 does not add:

- scraping
- browser automation
- eBay API calls
- dealer API calls
- auction API calls
- live listing retrieval
- automatic purchasing
- automatic collection mutation
- live pricing claims
- image recognition

## Future Roadmap

v3.7 prepares for v4.0 Live Deal Hunter by defining what future live sources must provide and how source output must be validated before any ranking or recommendation workflow consumes it.
