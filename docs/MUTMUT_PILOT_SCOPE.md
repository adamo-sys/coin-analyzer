# Mutmut Pilot Scope

Authorized source under mutation:

- `reviewer_agent.py`

Authorized focused test selection:

- `test_reviewer_agent.py`

Supporting copied modules:

- `improvement_agent.py`
- `diagnostic_agent.py`

Explicitly out of scope for this first pilot:

- operational handoff
- orchestrator
- Stage 10/11 experiment runtimes
- collection code
- prompts/models/config policy
- blocking CI requirements
- automatic remediation or promotion

Any scope expansion requires a separate bounded change after reviewing T6 evidence.
