# Coin Analyzer — Portfolio Overview

**Independent personal software project developed and maintained by Adam Osmak.**

Coin Analyzer is a local-first Windows desktop application for managing coin and banknote collections, tracking acquisition costs, analyzing portfolio coverage, reviewing OCR/image-recognition output, and asking grounded natural-language questions about collection data.

## What I built

- A Python/Tkinter desktop application for coin and banknote collection management.
- Local JSON persistence with explicit privacy boundaries and backward-compatible data handling.
- Deterministic portfolio analytics, duplicate/upgrade detection, acquisition workflows, and collection-quality tooling.
- Optional grounded AI integration using allowlisted read-only tools rather than model-generated calculations.
- OCR and image-recognition review workflows designed to require collector review before facts become authoritative.
- Extensive automated regression coverage across backend, persistence, workflows, integrations, and headless GUI behavior.
- Architecture decision records, engineering playbooks, testing documentation, and release/roadmap documentation.

## Skills demonstrated

Python · Tkinter · Git · GitHub · automated testing · software architecture · local-first design · privacy-by-design · API integration · grounded AI · OCR workflows · technical documentation · regression testing · data validation · deterministic analytics

## Engineering approach

The project emphasizes correctness and reviewability over opaque automation. Collection arithmetic is deterministic, persisted data is validated, AI access is optional and bounded, and OCR/image-recognition output remains advisory until reviewed by the collector.

The repository includes screenshots, a short demo GIF, architecture documentation, ADRs, a testing strategy, and a detailed README for technical reviewers.
