# v8.1 Batch Processing Implementation Plan

## Overview

Batch Processing (v8.1) extends the v8.0 Smart Phone Cataloguer to process an entire folder of photos through the existing pipeline in a single deterministic, offline workflow.

## Design Principle

Favor reuse over invention. `batch_processing.py` is an orchestration layer only.
No new OCR, no new matching, no new cataloguing logic.
Design the public API first; implementation stays thin.

## Phase 1: Core Engine — Public API Design

Design the interface before writing implementation:

```python
class BatchProcessingEngine:
    def process_folder(self, folder_path: str) -> BatchReport:
        ...
```

Or, if multiple sources are anticipated:

```python
class BatchProcessingEngine:
    def process(self, source: BatchSource) -> BatchReport:
        ...
```

Key types:
- `BatchSource` — folder path or list of photo paths
- `BatchCandidate` — per-photo candidate with capture, OCR, match, and proposal data
- `BatchReport` — consolidated report with items, summary, warnings, and export support
- `BatchResult` — per-item result with status (success, partial, failed)

## Phase 2: Integration with Photo Capture + OCR

- Reuse PhotoCaptureWorkflow for batch session creation
- Reuse OCRIdentificationEngine for batch identification
- Handle per-image failures gracefully
- Collect confidence scores and review flags per candidate

## Phase 3: Integration with Collection Intelligence

- Reuse Collection Intelligence for batch ownership/duplicate/upgrade/gap analysis
- Consolidated duplicate report across all candidates
- Consolidated upgrade opportunity ranking
- Consolidated gap analysis with series impact

## Phase 4: Batch Reporting & Export

- Consolidated batch report: per-item details + summary statistics
- Top opportunities from batch pool
- Batch warnings and review flags
- CSV export with all fields
- Markdown export with summary narrative
- Integration with Collection Dashboard batch summary panel

## Phase 5: GUI Integration

- Tools → Batch Processing menu item
- Folder selection dialog
- Progress dialog for batch operations
- Results review dialog with per-item expandable details
- Export buttons for CSV/Markdown
- Mobile-friendly layout reuse from v8.0

## Phase 6: Release

- Implement test_batch_processing.py
- Run full regression suite (959+ tests)
- Update release docs
- Create tag v8.1
- Push and verify

## Test Plan

- Unit tests for BatchProcessingEngine public API
- Integration tests: folder → batch → report
- Fixture tests with sample batch data
- Regression: full suite must pass

## Risk Areas

- Batch operations may be slow; progress indicators needed
- Partial failures must not corrupt batch state
- Memory usage with large batches
- GUI responsiveness during batch processing
