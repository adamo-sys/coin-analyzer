# Collector Journey

If a friction point cannot be reproduced during a real collecting session, it does not become a roadmap item.

Use this document to describe the ideal collecting experience and compare it against the current one.

Leave unknown friction blank until it is observed during a real Collector Journey Audit.

The collector experience, not the engineer, drives v8.7.

## Audit Rules

- Observe.
- Do not fix.
- Do not record implementation ideas during the session.
- Only record observations.
- Do not recommend Phase 1 before the audit.

## Baseline Metrics

Record these in `FRICTION_LOG.md` during the audit:

- total processing time
- number of pauses greater than 30 seconds
- number of tool switches
