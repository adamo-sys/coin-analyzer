# v7.5 Numista Intelligence Implementation Plan

## Overview
Numista Intelligence provides deterministic, offline analysis of Numista export data
to identify collection gaps, duplicates, upgrade opportunities, and acquisition targets
without live API calls, web scraping, or external services.

## Architecture
- `numista_intelligence.py` — core engine
- `test_numista_intelligence.py` — comprehensive test suite
- Minimal GUI integration in `coin_collection_gui.py` via Tools menu

## Core Components

### 1. NumistaDataModel
- Parse and normalize Numista Excel/CSV export fields
- Map Numista fields to internal collection schema
- Handle country, denomination, year, grade, variety, certification

### 2. NumistaCollectionAnalyzer
- Compare Numista export against local collection
- Identify: owned items, duplicates, upgrades, gaps, new varieties
- Reuse existing Collection Intelligence, Series Tracker, and Acquisition Impact engines

### 3. NumistaIntelligenceReport
- Gap analysis: missing dates/series from Numista perspective
- Duplicate detection: Numista items already in collection
- Upgrade detection: Numista items better than owned equivalents
- Variety detection: Numista varieties not in collection
- Acquisition priority scoring
- CSV and Markdown export

### 4. NumistaIntelligenceEngine (facade)
- Orchestrates data loading, analysis, and report generation
- No live network calls
- No collection mutation
- Deterministic local guidance only

## GUI Integration
- Tools → Numista Intelligence: load Numista export, run analysis, display report
- Minimal integration: file picker, run button, text display, export buttons
- Reuses existing report display patterns

## Testing Strategy
- Unit tests for all engine components
- Fixture-based tests with sample Numista data
- Integration tests with existing collection intelligence
- Regression: must pass alongside existing 919+ tests
