## GOAL

Build Mobile Companion Prototype.

IMPORTANT:

This is NOT:

* a native mobile app
* an iPhone app
* an Android app
* a web service
* an API server
* OCR
* image recognition

This is a prototype workflow proving that the Collector Operating System can support mobile-style usage.

Purpose:

Answer:

"Can a collector standing at a dealer table get a BUY/PASS recommendation in under 30 seconds?"

---

1. MOBILE COMPANION WORKFLOW

---

Create:

MobileCompanionWorkflow

Goal:

Single streamlined workflow:

Candidate
↓
Analyze
↓
Recommendation

without navigating multiple tools.

Reuse:

* Collection Intelligence
* Smart Shopping Assistant
* Acquisition Impact
* Collection Dashboard
* Collection Health Report
* Persistence Layer

Do not duplicate logic.

2. MOBILE CANDIDATE ENTRY

---

MobileCandidateEntry

Optimize for speed.

3. MOBILE ANALYSIS REPORT

---

Create:

MobileAnalysisReport

Output:

* BUY/PASS/NEGOTIATE/WATCH/REVIEW
* Impact Score
* Quality Delta
* Series Delta
* WANT_LIST status
* Top reason
* Recommendation summary

Keep report concise.

Collector should be able to read result quickly.
