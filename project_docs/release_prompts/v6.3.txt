PHASE 1
MISSION
=======

Create the device-linking and conflict-resolution layer.

Purpose:

Allow Collector Companion to model how multiple devices interact with the same collector workspace.

This release is NOT:

* internet sync
* real cloud providers
* user accounts
* authentication services
* automatic conflict resolution

Collector review remains mandatory.
