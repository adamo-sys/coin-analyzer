Begin v3.1 development.

Roadmap Context:

v3.0 = Collector Companion
v3.1 = eBay.ca Coin Deal Hunter MVP

GOAL:

Add a collection-aware Deal Hunter module that can ingest eBay.ca-style listing data from manual entry or CSV import.

This is an MVP.

Do not scrape live websites.

Do not use browser automation.

Do not require eBay API credentials.

Do not fetch live listing pages.

Build the internal engine, scoring model, import workflow, tests, and documentation so live sources can be added later.

---

1. DEAL HUNTER FEATURE

---

Add a new feature/tool called:

Deal Hunter

Purpose:

Evaluate candidate listings against Adam's collection, want list, and buying rules.

The tool should answer:

* Is this listing collection-relevant?
* Is this already owned?
* Is this an upgrade?
* Is this a gap filler?
* Is this a want-list match?
* Is this worth watching, negotiating, buying, reviewing, or passing?

---

2. INPUT MODEL

---

Create:

DealListing

Accept manual rows or CSV import.

Required / supported fields:

* title
* price_cad
* shipping_cad
* seller/source
* listing_url
* end_time/date optional
* image_url optional
* description optional

Normalize:

total_cost = price_cad + shipping_cad

All pricing is CAD.

If currency is not CAD or cannot be verified as CAD, flag REVIEW or PASS depending on severity.

4. LISTING PARSER

---

Parse title and description for:

* country
* year
* denomination
* series/type
* grade words
* slab company if present:

  * ICCS
  * CCCS
  * PCGS
  * NGC
  * BCS
  * PMG
* keywords:

  * silver
  * proof-like
  * specimen
  * large bust
  * near 6
  * wide 9
  * banknote
  * chartered banknote

Parsing should be deterministic.

Do not use live web lookups.

6. DEAL SCORING

---

Create deterministic deal scoring.

Output:

* estimated priority score 0-100
* liquidity score
* collection-fit score
* risk score
* max rational bid/price
* recommendation

Recommendations:

* BUY
* WATCH
* PASS
* NEGOTIATE
* REVIEW

Important:

Max rational bid/price is internal deterministic guidance only.

It is not live market pricing.

It is not appraisal.

It is not a guarantee of value.

---

7. ADAM'S BUYING RULES

---

Apply Adam's buying rules:

* Canadian sellers preferred
* CAD pricing only
* shipping included in total cost
* upgrades over duplicates
* pass if cool but not collection-relevant
* explicitly argue against purchase before recommending BUY

Priority boosts:

* Newfoundland
* Canadian silver
* 1859 Large Cent varieties
* 1973 Large Bust quarter
* 1926 Near 6 nickel
* Canadian banknotes
* chartered banknotes

Risk factors:

* high shipping
* missing grade
* vague title
* uncertain country/denomination
* raw coin with ambitious grade language
* non-Canadian irrelevant item
* unclear currency

---

8. CONTRARIAN BUY CHECK

---

Before recommending BUY, produce:

Counterargument

Examples:

* already have similar item
* shipping weakens deal
* grade uncertain
* price may be high
* better opportunities may exist

BUY should only remain BUY if the positive case survives the counterargument.
