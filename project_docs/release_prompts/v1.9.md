## GOAL

Build Smart Shopping Assistant.

Purpose:

Combine all existing collection intelligence systems into a single ranked purchasing recommendation workflow.

The assistant should answer:

* What should I buy next?
* Which current opportunities deserve attention?
* Which listings have the highest collection impact?
* Which WANT_LIST targets matter most?
* Which opportunities are overpriced?
* Which opportunities improve collection quality the most?

This release should prioritize opportunities.

Not just analyze them.

## DEFINITION OF DONE

The collector can open one workflow and determine:

* What to buy next
* Which opportunities are highest priority
* Which purchases improve the collection most
* Which purchases are overpriced
* Which purchases should be avoided

without manually reviewing multiple reports, dashboards, and engines.

v1.9 should represent the final major feature release before v2.0 Collector Operating System.
