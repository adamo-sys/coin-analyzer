Roadmap Context:

v2.0 = Collector Operating System
v2.1 = Persistence Layer
v2.2 = Data Safety and Backup Hardening

GOAL:
Build Data Safety and Backup Hardening.

Purpose:
Make the app safer to use by improving backup, restore, validation, and data-integrity workflows.

The collector should know:

* What data exists
* What data is backed up
* What data is missing
* Whether app state is valid
* Whether collection workbook paths are valid
* Whether recovery is possible

Do not add:

* OCR
* image recognition
* scraping
* APIs
* live pricing
* market prediction
* Numista integration
* cloud sync
* user accounts
* database server
* major UI redesign

---

1. BACKUP MANAGER

---

Create:

BackupManager

Support:

* create backup package
* verify backup package
* list available backups
* restore from backup package
* backup metadata report

Backup package should include, when available:

* app state JSON
* market records
* photo records
* shopping candidates
* release notes / release history
* backup manifest

Do not automatically modify or overwrite the collection workbook.

If collection workbook is included, do so only by explicit path reference or copied backup file if safe.

---

2. BACKUP MANIFEST

---

Create:

BackupManifest

Include:

* backup created timestamp
* app version
* included files
* excluded files
* missing files
* warnings
* checksum/hash where practical
* restore notes

Manifest should be human-readable.

Preferred format:

JSON

Optional companion:

Markdown summary

---

3. RESTORE WORKFLOW

---

Support restore from backup package.

Rules:

* Validate before restore
* Do not overwrite current files without backup
* Create pre-restore backup
* Report exactly what was restored
* Report skipped files
* Handle partial restore gracefully

No silent destructive behavior.

---

4. VALIDATION ENGINE

---

Create:

DataSafetyValidator

Validate:

* app state JSON exists
* app state JSON is valid
* collection workbook path exists
* WANT_LIST source path exists if applicable
* market records can load
* photo records can load
* shopping candidates can load
* referenced photo paths exist
* backup directory exists

Return:

DataSafetyReport

Include:

* PASS / WARNING / FAIL
* issues
* recommended actions

---

This is reporting/export only.

## DEFINITION OF DONE

The collector can:

* validate local app data
* create a backup package
* verify backup contents
* restore safely
* understand what is missing or unsafe

without manually inspecting files and folders.
