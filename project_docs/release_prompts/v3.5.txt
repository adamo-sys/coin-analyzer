PHASE 1
V3.5 EXTERNAL LISTING CONNECTORS
--------------------------------

GOAL

Create a connector framework that normalizes listing data from multiple sources.

Do NOT implement:

* scraping
* browser automation
* eBay APIs
* dealer APIs
* auction APIs
* live fetching

Framework only.

---

1. CONNECTOR FRAMEWORK

---

Create:

* ListingConnector
* ConnectorRegistry

Purpose:

Normalize external listing data into a common structure.

All connectors should output:

NormalizedListing

Compatible with:

* Deal Hunter
* Opportunity Engine
* Ranking Engine

---

2. BUILT-IN CONNECTORS

---

Implement:

eBayCSVConnector

AuctionCSVConnector

DealerInventoryConnector

GenericCSVConnector

These connectors should normalize source fields into a common listing model.

---

3. NORMALIZED LISTING MODEL

---

Ensure every imported listing can expose:

* title
* description
* price
* shipping
* total cost
* seller
* source
* source type
* URL
* image URL
* import timestamp
* connector name

---

4. IMPORT PIPELINES

---

Support:

* single-file imports
* multi-file imports
* mixed-source imports

Examples:

eBay CSV
+
Dealer CSV
+
Auction CSV

into one CandidatePool.

---

5. CONNECTOR VALIDATION

---

Create:

ConnectorValidationReport

Validate:

* required fields
* malformed prices
* malformed URLs
* missing titles
* unsupported columns
* import warnings

Do not silently discard invalid records.

---

6. SOURCE TRACKING

---

Every listing should record:

* connector used
* source name
* source type
* import date/time

Purpose:

Improve traceability.

---

7. CROSS-SOURCE DUPLICATE DETECTION

---

Create:

DuplicateOpportunityDetector

Detect:

* identical URLs
* same listing imported twice
* likely duplicate opportunities across sources

Flag duplicates for review.

Do not automatically remove them.

---

8. MULTI-SOURCE RANKING

---

Allow:

* Deal Hunter
* Opportunity Engine
* Ranking Engine

to operate on listings from multiple connectors simultaneously.

Preserve existing ranking behavior.

---

9. REPORTING

---

Create:

ConnectorImportReport

SourceSummaryReport

ConnectorValidationReport

Support:

* Markdown export
* CSV export
