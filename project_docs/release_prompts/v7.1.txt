## Guardrails

- **No AI:** Analytics are deterministic calculations, not AI recommendations
- **No Forecasting:** No predictions or future projections
- **No Machine Learning:** No ML models or training
- **No Cloud Analytics:** All analytics use local data only
- **No External APIs:** No external service calls or data sources
- **Deterministic:** All metrics are calculated from local platform state
- **Read-Only:** Analytics engine does not modify any data
- **Export-Only:** Export functionality writes to user-selected files only
