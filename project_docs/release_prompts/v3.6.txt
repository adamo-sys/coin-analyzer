Begin v3.6 development.

Roadmap Context:

v3.5 = External Listing Connectors
v3.6 = Deal Hunter Calibration
v4.0 = Live Deal Hunter

GOAL:

Calibrate Deal Hunter and Ranking behavior using realistic offline listing scenarios before adding live sources.

This release improves decision quality.

Do NOT add:

* scraping
* browser automation
* eBay APIs
* dealer APIs
* auction APIs
* live listing retrieval
* live pricing
* automatic purchasing
* collection mutation

---

1. CALIBRATION ENGINE

---

Create:

DealHunterCalibrationEngine

Purpose:

Compare expected collector judgment against actual Deal Hunter / Ranking output.

Support calibration cases with:

* listing data
* expected recommendation
* expected rank band
* expected risk flags
* expected rationale
* notes

4. SCORING CALIBRATION

---

Review and tune deterministic scoring only where justified by tests.

Focus:

* Newfoundland priority
* Canadian banknote priority
* chartered banknote priority
* Canadian silver priority
* upgrade vs duplicate handling
* high shipping penalty
* vague title penalty
* raw overgraded risk
* damaged/cleaned/holed penalty
* collection gap boost
* want-list boost
* budget-fit scoring

Do not claim market pricing accuracy.

---

5. RANKING CALIBRATION

---

Improve ranking where needed.

Check:

* Top 10 overall
* Top under $50
* Top under $100
* Top under $250
* Top Newfoundland
* Top banknote
* Top upgrade
* Top gap

Goal:

Better rank order, not more features.

7. FALSE POSITIVE / FALSE NEGATIVE REVIEW

---

Detect:

False BUY:
System recommends BUY when expected is PASS / REVIEW.

False PASS:
System recommends PASS when expected is BUY / WATCH / NEGOTIATE.

Ranking miss:
Strong opportunity ranked too low.

Risk miss:
Risk factor not flagged.

---

8. EXPLANATION CALIBRATION

---

Verify explanations match recommendation.

For BUY:

* must include counterargument
* must justify why positive case survives

For PASS:

* must clearly explain collection irrelevance, duplicate status, risk, or poor fit

For REVIEW:

* must identify uncertainty
