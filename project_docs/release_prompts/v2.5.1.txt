Begin v2.5.1 development.

Roadmap Context:

v2.5 = Photo-Assisted Entry
v2.5.1 = Photo Vault Hardening

GOAL:

Improve photo reliability, coverage, and trustworthiness.

Purpose:

Ensure photo references are useful, findable, valid, and safely reportable.

This is a hardening release.

Do not add:

* OCR
* image recognition
* AI grading
* scraping
* APIs
* live pricing
* cloud sync
* database server
* Numista integration

---

1. PHOTO VAULT INTEGRITY AUDIT

---

Create or enhance:

PhotoVaultIntegrityAudit

Output:

PhotoCoverageReport

Detect:

* missing photo files
* invalid photo paths
* duplicate photo references
* unlinked photo records
* collection items without photos
* candidates without photos
* certification-linked items without photos
* orphan photo metadata

Report only.

Do not move, delete, rename, or modify photo files.

---

Use available metadata only.

## DEFINITION OF DONE

A collector can answer:

"Are my photo records trustworthy?"

using a single Photo Vault audit/report.

The system identifies:

* missing photos
* invalid photo references
* duplicate photo records
* unlinked photo metadata
* photo coverage gaps

without performing OCR, image recognition, or automatic file changes.
