==================================================
PHASE 3
LISTING VALIDATION RULES
========================

Validate:

* title exists
* price exists
* URL exists
* seller exists
* source exists

Flag:

* missing title
* missing price
* missing URL
* missing seller
* missing source

Never silently accept malformed listings.

==================================================
PHASE 4
CURRENCY VALIDATION
===================

Validate:

* CAD
* USD
* unknown currency

Flag:

* NON_CAD
* UNKNOWN_CURRENCY

Do NOT convert currencies.

Do NOT fetch exchange rates.

Do NOT claim equivalent values.

==================================================
PHASE 5
STALE LISTING DETECTION
=======================

Create:

ListingFreshness

Values:

* FRESH
* STALE
* UNKNOWN

Use timestamps supplied by the feed.

Do not use live time lookups beyond normal system time.

==================================================
PHASE 6
URL VALIDATION
==============

Validate:

* malformed URLs
* duplicate URLs
* empty URLs
* unsupported URL schemes

Flag issues.

Do not automatically repair URLs.
