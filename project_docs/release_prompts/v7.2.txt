## Guardrails

**Strictly Forbidden:**
- AI reasoning, forecasting, or machine learning
- External APIs or web services
- Automatic collection mutations
- Automatic purchasing or bidding
- Background jobs
- Non-deterministic insights

**Required:**
- All insights must be deterministic and explainable
- All insights must derive from local collection data only
- Confidence scores based on data completeness, not AI certainty
- Insights must be evidence-based with supporting metrics
- Insights must be actionable with clear explanations
