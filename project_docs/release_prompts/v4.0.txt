PHASE 1
MISSION
=======

Collector Companion now discovers opportunities.

The collector remains in control.

The system may:

* fetch listings
* validate listings
* score listings
* rank listings
* explain listings

The system may NOT:

* purchase items
* place bids
* mutate collection records
* run hidden background jobs
* perform automatic monitoring
* perform automatic refreshes

All live activity must be explicitly user-triggered.

DEFINITION OF DONE
==================

Collector Companion can retrieve listings from one real public source, validate them, normalize them, rank them, evaluate them through the existing intelligence stack, and present opportunities to the collector while remaining completely user-controlled.

This is the first release where Collector Companion discovers opportunities instead of waiting for imported listings.
