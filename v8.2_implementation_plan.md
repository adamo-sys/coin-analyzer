# v8.2 AI Grading Assistant Implementation Plan

## Overview

AI Grading Assistant (v8.2) provides deterministic, explainable coin grading guidance by analyzing collection grade patterns and candidate evidence without computer vision or automated grade assignment.

## Standard Release Lifecycle

        ↓

        ↓
Phase 6 — Release (final regression, metadata, tag, commit)
        ↓
Publish (push main, push tag, verify remote)

## Design Principle

Favor reuse over invention. `ai_grading_assistant.py` is an orchestration and evidence layer only.
No new image processing, no computer vision, no automated grade assignment.

## API-First Design

Before implementation, define the public API:

```python
class AIGradingAssistant:
    def assess_candidate(self, candidate: GradingCandidate) -> GradingAssessment
    def assess_batch(self, candidates: List[GradingCandidate]) -> BatchGradingReport
    def get_collection_grade_patterns(self, country: str, denomination: str) -> GradePattern
    def export_assessment(self, assessment: GradingAssessment, format: str) -> str
```

## Phase Breakdown

### Phase 1 — Core Engine
- Design `GradingCandidate`, `GradingAssessment`, `GradePattern`, `BatchGradingReport` dataclasses
- Implement `AIGradingAssistant` with collection grade pattern analysis
- Implement confidence scoring based on evidence quality
- Unit tests for public API

### Phase 2 — Photo Vault + OCR Integration
- Link photo metadata to grading candidates
- Integrate OCR identification evidence (optional)
- Handle missing/weak evidence gracefully

### Phase 3 — Collection Intelligence Integration
- Analyze grade distribution from existing collection
- Identify patterns (typical grades, outliers, upgrades)
- Flag candidates outside typical range

### Phase 4 — Workflow
- Batch assessment for multiple candidates
- Assessment reporting with evidence breakdown
- CSV/Markdown export
- Review flagging and escalation

### Phase 5 — GUI
- Tools → AI Grading Assistant menu item
- Manual candidate entry dialog
- Assessment display with expandable evidence
- Batch assessment dialog with progress

### Phase 6 — Release
- Final regression (1015+ tests)
- Metadata updates
- Tag v8.2
- Commit and push
- Verify remote
